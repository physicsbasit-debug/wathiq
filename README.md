# واثق — اختبارات علوم موثقة تقيس التعلم بسياقات متنوعة

## Phase 1-D2 — جودة القياس وتنوع السياقات

الإصدار الحالي: **`0.0.48`**  
إصدار عقد التوليد: **`source-grounded-policy-ai-16-assessment-quality-context-diversity`**

تعالج هذه المرحلة تكرار الأسئلة المباشرة والرسوم المتشابهة وغياب مواقف حياة الطالب. يبني واثق الآن مخطط جودة قبل التوليد يحدد لكل مفردة هدف التعلم والمهارة والسياق ونوع المثير والرسم المناسب، ثم يرفض الخطط والأسئلة التي لا تحقق حدًا أدنى من التنوع.

### ما تغير

- تمرير **هدف التعلم** نفسه إلى مولد السؤال، لا اسم الدرس فقط.
- توزيع الاختبار بين: مفهوم، سياق حياتي، مقارنة، بيانات، استقصاء، وحساب.
- حصر سؤال التعريف أو الوحدة المباشر في مفردة واحدة في الاختبار القصير.
- إضافة سياقات: الباب، الأرجوحة، مفتاح الربط، الدراجة، عربة التسوق، الحقيبة، خزان الماء، الطاقة الشمسية، المختبر، وسلامة الطريق.
- إنشاء رسم SVG احتياطي مختلف لكل سياق بدل تكرار الشكل نفسه.
- توجيه صورة Gemini ثنائية الأبعاد بوصف خاص بكل سياق مع منع التكوينات الجاهزة المكررة.
- رفض البدائل الثلاثة إذا كانت مجرد إعادة صياغة للسؤال نفسه.
- رفض السؤال الحياتي إذا كان السياق زخرفيًا أو لا يطابق الخطة.
- رفض خطة الاختبار إذا كانت فقيرة في المهارات أو السياقات أو أساليب القياس.

### ما بقي محميًا

- المرجع المدرسي وصفحات الدرس هي المصدر الحاكم.
- مواصفات التقويم العُمانية تظل حاكمة للدرجات والأنواع.
- أسلوب كامبريدج مصدر إلهام لبناء المفردة، لا مصدرًا بديلًا للمنهج.
- الرسوم الحتمية تبقى الأساس للمخططات التي تؤثر في صحة الحل.
- صور AI تبقى طبقة سياقية مدققة مع رجوع آمن إلى SVG.
- لا تغيير في SQL أو الفهرسة أو Word أو PDF أو آلية الاعتماد.
- تقليل استهلاك Gemini مستمر عبر الدفعات الصغيرة وحد أقصى للصور التلقائية.

## الأساس الموروث

يبقى **Phase 1-C1** ومبدأ مواصفة SVG حتمية وآمنة أساس محرك الرسومات، وتستمر تحسينات C2 وC3 وC4 وD1 دون تغيير. تضيف Phase 1-D2 طبقة جودة وتقويم قبل التوليد، ولا تستبدل البنية السابقة.

```text

```
