# واثق — Phase 0-B UX Shell

نموذج تفاعلي محلي يثبت تجربة المعلم الأساسية قبل ربط المصادر أو الذكاء الاصطناعي أو Google Drive.

## ما الذي يعمل؟

- واجهة عربية RTL ومتجاوبة.
- الصفحة الرئيسية.
- مسار إنشاء اختبار في أربع خطوات.
- حفظ تلقائي محلي للمسودة باستخدام `localStorage`.
- تحقق تجريبي من مجموع الدرجات.
- بناء خطة محلية تجريبية.
- ثلاثة مقترحات متكافئة لكل مفردة.
- إعادة توليد مفردة واحدة دون بقية الخطة.
- معاينة القالب باسم «وزارة التعليم».
- صفحة «اختباراتي».
- هيكل أولي للوحة إدارة المصادر وترتيب Google Drive.

## ما الذي لا يعمل عمدًا؟

- لا ربط حقيقي مع Google Drive.
- لا قراءة PDF أو فهرسة.
- لا ذكاء اصطناعي حي.
- لا توليد علمي حقيقي.
- لا تصدير Word أو PDF حقيقي.
- لا حسابات أو اشتراكات إنتاجية.

البيانات والمحتوى العلمي داخل النموذج **تجريبية فقط** ولا تمثل المنهج العُماني الرسمي.

## التشغيل

يتطلب Node.js 20 أو أحدث، وTypeScript متاحًا بعد `npm install`.

```bash
npm install
npm run check
npm run dev
```

ثم افتح:

```text
http://localhost:4173
```

يوجد أيضًا مجلد `dist/` جاهز بعد البناء.

## بنية المشروع

```text
src/
├── app.ts       # الواجهة والتفاعل
├── data.ts      # بيانات تجريبية محلية
├── domain.ts    # التحقق وبناء الخطة
├── storage.ts   # الحفظ المحلي
├── styles.css   # التصميم RTL والمتجاوب
├── types.ts     # الأنواع
└── ui.ts        # أدوات العرض
```

## قرار المرحلة

هذه المرحلة تختبر سهولة الاستخدام فقط. اختيار البنية الخلفية النهائية ومحرك المصادر يأتي بعد قبول تجربة المستخدم، حتى لا نبني محرك طائرة لواجهة تحتاج دراجة.
