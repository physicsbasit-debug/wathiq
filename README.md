# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## المرحلة الحالية

**Phase 0-G — استخراج النص القابل للتحديد من PDF وفهرسته**

تقرأ هذه المرحلة ملفات PDF المرفوعة في Google Drive من داخل متصفح مالك المنصة، ثم تحفظ ملخص الاستخراج ومقاطع النص في Supabase. لا تنفذ OCR ولا تعتمد العناوين المكتشفة بوصفها وحدات أو دروسًا رسمية.

## ما يعمل في هذه المرحلة

- تنزيل PDF عبر مسار آمن في Edge Function مع دعم طلبات Range.
- استخراج النص القابل للتحديد صفحة صفحة بواسطة PDF.js.
- عرض تقدم الاستخراج في واجهة إدارة المصادر.
- حساب عدد الصفحات والحروف واللغة التقريبية.
- اكتشاف عناوين مرشحة بقواعد نصية بسيطة.
- تقسيم النص إلى مقاطع مرتبطة بأرقام الصفحات.
- حفظ المقاطع داخل `source_chunks` في Supabase.
- إعداد فهرس بحث نصي باستخدام إعداد PostgreSQL `simple`.
- وسم الملف المصور الذي لا يحتوي نصًا كافيًا بأنه **يحتاج OCR**.
- إعادة الاستخراج للمصدر نفسه مع استبدال المقاطع القديمة.
- إبقاء الأرشفة والاستعادة دون حذف المقاطع.

## إعداد المرحلة

1. نفّذ SQL الموجود في:
   - `supabase/phase_0_g_pdf_extraction.sql`
2. استبدل كود Edge Function الحالية بالكود الموجود في:
   - `supabase/functions/google-drive-oauth/index.ts`
3. أبقِ خيار `Verify JWT with legacy secret` مغلقًا.
4. ارفع ملفات التطبيق إلى GitHub وانتظر نجاح الفحوص والنشر.
5. افتح مصدر PDF مرفوع واضغط **استخراج وفهرسة**.

## ضوابط الصدق والجودة

- حالة **مفهرس** تعني أن النص القابل للتحديد استُخرج وحُفظ، ولا تعني أن الوحدات والدروس راجعت تربويًا.
- العناوين الظاهرة في التفاصيل مرشحة فقط.
- الملف الذي لا يحتوي نصًا كافيًا لا يُعامل على أنه مقروء، بل ينتقل إلى **يحتاج مراجعة / يحتاج OCR**.
- OCR واستخراج الرسوم والصور خارج نطاق هذه المرحلة.

## ما لم يتغير

- `.github/workflows/pages.yml` لم يتغير في Phase 0-G.
- لا توجد متغيرات GitHub جديدة.
- لا توجد أسرار Supabase جديدة.
- لا توجد Edge Function جديدة؛ جرى تحديث `google-drive-oauth` الحالية فقط.

## خارج نطاق Phase 0-G

- OCR للملفات المصورة.
- اعتماد الوحدات والدروس ونواتج التعلم تلقائيًا.
- استخراج الصور والرسوم والجداول.
- إنشاء embeddings أو استخدام نموذج ذكاء اصطناعي.
- توليد الأسئلة.

## العمل عبر GitHub

- كل مرحلة في فرع مستقل.
- يفتح Pull Request إلى `main`.
- لا دمج قبل نجاح GitHub Actions والمراجعة العملية.
- تُسلَّم حزمة ملفات معدلة فقط وحزمة كاملة احتياطية.
