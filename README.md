# واثق — اختبارات علوم موثقة بمرئيات تقويمية منظمة

## Phase 1-C3 — محرك المرئيات التقويمية المتقدمة

يبني هذا الإصدار على أساس **Phase 1-C1** للرسومات العلمية الحتمية، ثم يوسعه إلى أدوار وقوالب تقويمية أكثر تنوعًا.

يحوّل واثق المرئي من صورة مساندة إلى جزء من المفردة التقويمية: يقرأه الطالب، أو يحسب منه، أو يفسره، أو يقارن بين بياناته، أو يكمله، أو يرسم عليه، أو يقيمه.

### الأنواع المدعومة في هذا الإصدار

- رسوم خطية أحادية ومتعددة السلاسل.
- رسوم أعمدة.
- جداول بيانات علمية، مع إمكانية إخفاء خلية ليكملها الطالب.
- تدريجات أجهزة القياس: ميزان حرارة، سحاحة، مخبار مدرج، أميتر وفولتميتر.
- مخططات الأشعة: انعكاس، انكسار، عدسة محدبة، ومنشور.
- مخططات القوى: جسم حر، قوى متزنة، وعزوم.
- مخططات العمليات: تسلسل خطي، دورة، وتحولات الحالة أو الطاقة.
- الأنواع السابقة: الضغط، الدوائر الكهربائية، والكهرباء الساكنة.

### مبدأ الأمان

- الرسومات تُبنى داخل الخادم والواجهة من **مواصفة SVG حتمية وآمنة**.
- لا تُرسل طلبات توليد صور حرة إلى Gemini.
- لا يضاف استهلاك خاص بتوليد الصور.
- تمر المواصفة البصرية بفحص بنيوي قبل عرضها أو تصديرها.
- تبقى الرسومات واضحة في الطباعة بالأبيض والأسود وداخل Word وPDF.

### حدود هذه المرحلة

لا تتضمن المرحلة الحالية الصور المجهرية أو التشريحية الواقعية، واقتصاص صور الكتاب، وطبقة إجابة رسومية منفصلة يرسم عليها الطالب. هذه عناصر لاحقة لأنها تحتاج إدارة حقوق المصدر وربط مواضع الصور وصفحاتها، لا مولد صور حرًا.
