# واثق — اختبار علوم موثّق وفق المرجع الرسمي

## Phase 1-B2 — مرجع التقويم والقالب الرسمي

أصبح واثق يربط بين مصدرين منفصلين بوضوح:

1. **المحتوى العلمي:** كتب الطالب والمصادر المفهرسة، ومنها يستخرج النص والدليل ورقم الصفحة.
2. **مرجع التقويم:** وثيقة تقويم تعلّم الطلبة في مواد العلوم للصفوف (5-10)، إصدار 2025/2026، ومنها يحدد بنية الاختبار وضوابط المفردات.

### ما يفعله واثق الآن

- يعرض صفحة مستقلة باسم **مرجع تقويم العلوم** مع ملخص عملي ورابط الوثيقة الأصلية.
- يطبق تلقائيًا قالب اختبار قصير متوافقًا مع الصف المختار من 5 إلى 10.
- يثبت توزيع درجات أهداف التقويم: 40% معرفة، 40% تطبيق، 20% استدلال.
- يمنع الأعداد والدرجات المخالفة قبل التوليد.
- يبني مفردات بدرجات صحيحة: اختيار من متعدد بدرجة، قصيرة بدرجة أو درجتين، وطويلة للصفين 9 و10 فقط بثلاث أو أربع درجات.
- يولد ثلاثة بدائل لكل مفردة من صفحات الكتاب المفهرس، مع إجابة ودليل نصي ورقم صفحة.

### متطلبات التشغيل

- إعداد Supabase الحالي وتسجيل دخول مالك المنصة.
- وجود السر `GEMINI_API_KEY` في Supabase.
- نشر Edge Function باسم `generate-source-questions` من محرر Supabase بعد دمج التعديلات.

### الفحص

```bash
npm run check
```

لا يوجد SQL جديد، ولا إعادة فهرسة للمصادر الموجودة.
