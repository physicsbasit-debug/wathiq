# واثق

نموذج تجربة المستخدم للنسخة الأولى من منصة «واثق» لإنشاء الاختبارات القصيرة في مواد العلوم.

## المرحلة الحالية

**Phase 0-B — UX Shell**

تثبت هذه المرحلة رحلة المعلم عبر أربع خطوات واضحة قبل ربط الذكاء الاصطناعي أو المصادر
أو Google Drive ربطًا إنتاجيًا.

## ما يعمل في النموذج

- واجهة عربية RTL ومتجاوبة.
- الصفحة الرئيسية.
- إنشاء اختبار عبر أربع خطوات.
- حفظ تلقائي محلي للمسودة.
- تحقق تجريبي من مجموع الدرجات.
- خطة اختبار محلية تجريبية.
- ثلاثة مقترحات متكافئة لكل مفردة.
- إعادة توليد مفردة واحدة.
- معاينة القالب باسم «وزارة التعليم».
- صفحة «اختباراتي».
- هيكل أولي للوحة إدارة المصادر.

## ما لا يعمل عمدًا

- لا ربط حقيقي مع Google Drive.
- لا قراءة PDF أو فهرسة.
- لا ذكاء اصطناعي حي.
- لا توليد علمي حقيقي.
- لا تصدير Word أو PDF حقيقي.
- لا حسابات أو اشتراكات إنتاجية.

المحتوى العلمي في النموذج تجريبي ولا يمثل المنهج العُماني الرسمي.

## العمل عبر GitHub

- كل مرحلة تنفذ في فرع مستقل.
- يفتح Pull Request إلى `main`.
- يشغّل GitHub Actions البناء والاختبارات تلقائيًا.
- لا يدمج الطلب قبل نجاح الفحوص والمراجعة البصرية.
- ينشر `main` تلقائيًا كمعاينة عبر GitHub Pages بعد تفعيل Pages من إعدادات المستودع.
