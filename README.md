## Phase 0-H1 Rebuild 1 — مرجع ذهبي لاستخراج الفهرس

تعيد هذه المرحلة بناء محرك هيكل الكتاب على اختبار قبول مطابق للفهرس الحقيقي لكتاب الفيزياء للصف العاشر.

### الضمانات الجديدة

- لا يُحفظ استخراج ناقص.
- لا تُستخدم عناوين صفحات المحتوى كبديل تلقائي للفهرس.
- يفهم ترتيب: رقم الصفحة ← عنوان الدرس ← رمز الدرس، والعكس.
- يربط الدرس بوحدته عبر رقم الوحدة، لا ترتيب OCR.
- يقبل العناوين القصيرة الصحيحة مثل «القدرة» و«المنصهرات».
- يعزل المسودات القديمة التي تتكون من وحدات فقط بلا دروس.
- المرجع الذهبي الإلزامي: 11 وحدة و29 درسًا مع وجود الوحدة الأولى.
