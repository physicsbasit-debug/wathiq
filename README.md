# واثق — اختبارات علوم موثّقة من المصدر

## Phase 1-B8 — مواءمة أسلوبية مع الاختبارات العلمية الدولية

يرفع هذا الإصدار جودة بناء الأسئلة مع الحفاظ على المرجع العُماني الحاكم. يستفيد واثق من ممارسات كامبريدج في تنظيم السياق، وقراءة البيانات، والحساب، والاستقصاء، والمفردات المترابطة، دون نسخ أسئلة خارجية أو تغيير توزيع الدرجات العُماني.

### ما يعمل في هذا الإصدار

- ستة أنماط لبناء السؤال: مفهومي، سياقي، حسابي، بيانات، استقصائي، مقارنة.
- تحديد نمط كل مفردة من الخطة الرسمية قبل استدعاء Gemini.
- متن أو بيانات إلزامية للأنماط التي تحتاجها.
- نقطة تصحيح مستقلة لكل درجة.
- مشتتات اختيار من متعدد مبنية على أخطاء علمية أو حسابية محتملة.
- تجميع الأسئلة الإنشائية بحسب الدرس في أسئلة منظمة ذات أجزاء فرعية.
- إخفاء مراجع الصفحات من ورقة الطالب، مع إبقائها في نموذج المعلم.
- استمرار الاستناد إلى مقاطع الأدلة المرقمة التي يثبتها الخادم.
- استمرار الدروس المتعددة والتوليد الدفعي وقوالب التقويم الرسمية.

### متطلبات التشغيل

- `GEMINI_API_KEY` و`WATHIQ_APP_URL` في أسرار Supabase.
- `GEMINI_MODEL` اختياري، والقيمة الافتراضية `gemini-2.5-flash`.
- إعادة نشر وظيفة `generate-source-questions` بعد الدمج.

### الفحص

```bash
npm run check
```

لا يوجد SQL جديد، ولا حاجة إلى إعادة فهرسة المصادر أو تغيير مفتاح Gemini.
