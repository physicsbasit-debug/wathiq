- لا يكرر العبارة إذا ذكر السؤال أو المثير الرسم مسبقًا.
- يجري التطبيع قبل فحص كفاية السياق والارتباط العلمي.
- تبقى المسودة على محرك V2، ولا تتحول إلى المحرك السابق.
