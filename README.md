# واثق

## Phase 0-H1 Rebuild 2 — الفهرس البصري بإحداثيات الكلمات

تعيد هذه المرحلة بناء استخراج هيكل الكتاب من صفحة الفهرس المصوّرة نفسها، لا من النص المسطح. تستخدم واثق إحداثيات كل كلمة من Google Cloud Vision لفصل العمود الأيمن عن الأيسر، ثم تربط رموز الدروس بالوحدات وأرقام الصفحات.

### النتيجة المطلوبة للمرجع الحقيقي

- 11 وحدة.
- 29 درسًا.
- الوحدة الأولى موجودة وتبدأ من صفحة 15.
- الوحدة الحادية عشرة تبدأ من صفحة 109.
- لا أرقام صفحات داخل العناوين.
- لا حفظ لأي نتيجة ناقصة أو غير متسلسلة.

### التغييرات

- مسار Edge Function جديد: `ocr-layout-page`.
- تخزين `layout_json` داخل `source_ocr_pages` لإعادة استخدام التحليل دون تكلفة Vision إضافية.
- تحليل صفحة PDF بدقة مرتفعة وبحد آمن للبكسلات.
- فصل العمودين بحسب الإحداثيات الفعلية.
- دعم التفاف عنوان الوحدة أو الدرس على سطرين.
- التحقق من تسلسل الوحدات والدروس وتصاعد أرقام الصفحات قبل الحفظ.
