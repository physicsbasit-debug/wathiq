# واثق — اختبارات علوم موثّقة من شجرة الكتاب

## Phase 1-C2 Fix 3 — شجرة الكتاب والوحدات والدروس

أصبح اختيار محتوى الاختبار يتم بطريقة واحدة واضحة:

1. اختيار الصف والمادة.
2. فتح اسم الكتاب.
3. فتح الوحدة.
4. تحديد من درسين إلى خمسة.
5. الانتقال إلى إعداد الاختبار.

لا إدخال يدوي لأسماء الدروس، ولا كتابة أرقام، ولا إعادة فهرسة متكررة.

### الكتاب المدعوم مباشرة في هذه المرحلة

- كتاب الطالب للفيزياء، الصف العاشر، الفصل الأول.
- 11 وحدة و29 درسًا مع نطاقات الصفحات.

تظهر الشجرة تلقائيًا للمصدر المطابق لرقم الفهرسة والصف والمادة والفصل ونوع الكتاب. وإذا وجد واثق هيكلًا معتمدًا محفوظًا لمصدر آخر، يعرضه بالطريقة الهرمية نفسها.

### تحسين الاسترجاع

عند اختيار درس، يحصر واثق البحث في:

- المصدر الذي ينتمي إليه الدرس.
- نطاق صفحات الدرس داخل الكتاب.

ثم يرتب المقاطع داخل هذا النطاق، بدل البحث في الكتاب كاملًا. هذا يقلل احتمال سحب أسئلة من وحدة أخرى.

### لا يتغير

- لا SQL جديد.
- لا أسرار جديدة.
- لا تعديل على وظيفة `generate-source-questions`.
- لا حاجة إلى إعادة فهرسة الكتاب الحالي.
- لا استهلاك Gemini لبناء الشجرة.
