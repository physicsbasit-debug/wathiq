# واثق — اختبار قصير موثّق من المصدر

## Phase 1-B — توليد الأسئلة من صفحات الكتاب

أصبح مسار الاختبار يعمل من البداية إلى مسودة قابلة للمراجعة:

1. يختار المالك الصف والمادة ويكتب موضوع الاختبار.
2. يسترجع واثق أفضل المقاطع من المصادر المفهرسة مع أرقام الصفحات.
3. يبني خطة الاختبار وفق النوع والمستوى المعرفي والدرجة.
4. تستدعي الواجهة Edge Function آمنة لتوليد ثلاثة بدائل لكل مفردة من نص المرجع فقط.
5. يعرض كل بديل مع الإجابة النموذجية، سبب الإجابة، ودليل نصي من المصدر.
6. يختار المعلم سؤالًا واحدًا لكل مفردة ثم يراجع ورقة الاختبار ونموذج الإجابة.

### حدود المرحلة

- لا تحليل فهرس بصري.
- لا إدخال يدوي لأرقام الصفحات.
- لا توليد بلا مصدر مفهرس وتطابق واضح.
- لا يُرسل مفتاح OpenAI إلى المتصفح؛ يبقى داخل Supabase Edge Function.
- الأسئلة تبقى مسودة تحتاج مراجعة المعلم قبل الاستخدام.
- تصدير Word وPDF مؤجل، ولا تدّعي الواجهة أنه يعمل.

### متطلبات التشغيل

- إعداد Supabase الحالي للمصادر وتسجيل دخول مالك المنصة.
- نشر Edge Function باسم `generate-source-questions`.
- إضافة سر `OPENAI_API_KEY` في Supabase.
- يمكن ضبط `OPENAI_MODEL` اختياريًا، وإلا تستخدم الوظيفة `gpt-5-mini`.

### الفحص المحلي

```bash
npm run check
```

يشغّل الأمر بناء TypeScript ثم جميع اختبارات Node.
