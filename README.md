## أهم التغييرات

### استئناف ذري للمسودة

- تحفظ لقطة شجرة الدروس والوحدة النشطة ومفتاح اختيار المصدر **داخل المسودة نفسها**، لا في سجل منفصل فقط.
- يحافظ الحفظ المتأخر على آخر شجرة صحيحة ولا يستبدلها بلقطة فارغة.
- يفتح زر «متابعة» معرف المسودة المطلوبة فقط؛ إذا فقد المعرف لا يفتح مسودة أخرى أو اختبارًا جديدًا بالخطأ.
- تستعيد المسودات القديمة شجرة احتياطية من مراجع المصدر وعناوين الدروس عند غياب اللقطة.
- وجود أسئلة مولدة أو خطة حقيقية يمنع ترقية السياسة أو عقد التوليد من مسح العمل وإعادته إلى الخطوة الأولى.
- تعرض واجهة المعالج «متابعة المسودة المحفوظة» بدل «إنشاء اختبار جديد» عند استئناف عمل قائم.

### تحسين سلامة الاختبار

- أسئلة العزم في المواقف الحياتية يجب أن تحدد محور الدوران أو نقطة الارتكاز أو ذراع القوة أو موضع تأثيرها.
- يقل ارتفاع المشاهد السياقية في Word/PDF لتقليل الصفحات الزائدة مع إبقاء الرسوم الحسابية واضحة.
