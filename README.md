# واثق — اختبارات علوم موثّقة من المصدر

## Phase 1-B6 — تثبيت الاتصال المنظم مع Gemini

يعالج هذا الإصدار فشل التوليد الذي كان يظهر بعد نجاح تحليل JSON برسالة **«بنية الأسئلة المولدة غير صالحة»**. السبب في المسار السابق أن تكامل Interactions المستخدم لم يُرجع دائمًا الكائن الجذري المطلوب `items` مع النموذج `gemini-2.5-flash`، رغم أن النص الناتج كان JSON صالحًا.

### ما يعمل في هذا الإصدار

- استخدام `generateContent` المتوافق رسميًا مع `gemini-2.5-flash` للمهمة الأحادية الحالية.
- طلب مخرجات JSON منظمة عبر `responseMimeType: application/json` و`responseJsonSchema`.
- إلزام الناتج بالمفتاح الجذري `items` وبمعرفات مفردات الدفعة نفسها.
- قراءة جميع أجزاء `candidates[0].content.parts` والتحقق من `finishReason` قبل قبول الناتج.
- إبقاء التوليد في دفعات من مفردتين، مع إعادة محاولة الدفعة الفاشلة فقط.
- التحقق الخادمي من ثلاثة بدائل لكل مفردة، وأربعة خيارات للاختيار من متعدد، والدليل النصي من المصدر.
- تسجيل مراحل آمنة تشمل حالة الاستجابة وعدد العناصر والمفاتيح الجذرية عند فشل البنية، دون تسجيل المفتاح أو نص الكتاب.
- استمرار دعم الدروس المتعددة وقوالب التقويم الرسمية وعناوين الاختبارات وتاريخها.

### متطلبات التشغيل

- إعداد Supabase الحالي وتسجيل دخول مالك المنصة.
- وجود `GEMINI_API_KEY` و`WATHIQ_APP_URL` في أسرار Supabase.
- `GEMINI_MODEL` اختياري، والقيمة الافتراضية `gemini-2.5-flash`.
- إعادة نشر الوظيفة `generate-source-questions` من محرر Supabase بعد دمج التعديلات.

### الفحص

```bash
npm run check
```

لا يوجد SQL جديد، ولا حاجة إلى إعادة فهرسة المصادر الجاهزة أو تغيير مفتاح Gemini.
