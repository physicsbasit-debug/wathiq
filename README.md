# واثق — محرك تصميم الاختبار الكامل V2

## Phase 2-A — Whole Exam Generation V2

الإصدار الحالي: **`0.0.50`**  
عقد التوليد الجديد: **`source-grounded-policy-ai-17-whole-exam-v2`**

تضيف هذه المرحلة محركًا جديدًا يعمل بجانب المحرك السابق، ويصمم الاختبار القصير كاملًا في طلب مترابط بدل توليد الأسئلة على دفعات منفصلة ثم محاولة جمعها لاحقًا.

## ما تغير

- أصبح وضع **تصميم الاختبار كاملًا** هو الوضع الافتراضي للاختبارات القصيرة حتى 12 مفردة.
- بقي **المحرك السابق** متاحًا بوصفه خطة رجوع آمنة.
- إنشاء بطاقات درس تشغيلية تلقائيًا من أهداف الخطة ومراجع كتاب الطالب أو دليل المعلم.
- بناء مخطط شامل يحفظ الهدف والمهارة والسياق والمثير والرسم والدرجة لكل مفردة.
- إرسال الاختبار كاملًا إلى Supabase Edge Function عبر `generate_exam_v2`.
- توليد سؤال نهائي واحد لكل مفردة مع اختياره تلقائيًا، مع بقاء تجديد المفردة منفردة متاحًا.
- مراجعة شاملة تمنع تكرار نص السؤال، وإعادة مجموعة البيانات العددية نفسها، والإفراط في الاستدعاء المباشر، والتكرار المفرط لبنية الرسم.
- دعم تمرير مراجع الاختبارات العالمية عندما تكون موجودة ضمن مراجع المسودة، مع بقاء بطاقة الدرس والمنهج العُماني حاكمين.

## الحماية

- لم يُحذف المحرك السابق.
- الاختبارات التي تزيد على 12 مفردة تستخدم المحرك السابق في هذه المرحلة.
- لم يتغير SQL أو الفهرسة أو Word/PDF أو تخزين الصور.
- المسودات القديمة تُرحّل بأمان، ولا تُحذف أسئلتها.
- إعادة توليد مفردة واحدة تبقى ممكنة دون إعادة الاختبار كاملًا.

- شاشة مستقلة لاستخراج واعتماد بطاقات الدروس من دليل المعلم وكتاب الطالب.
- مزامنة بنك الاختبارات العالمية من Google Drive.
- توسيع V2 للاختبارات النهائية الكبيرة بعد نجاح الاختبارات القصيرة الحية.
