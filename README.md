# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## المرحلة الحالية

**Phase 0-F1 — ربط Google Drive وإنشاء المجلدات الأساسية**

تضيف هذه المرحلة اتصالًا آمنًا بين حساب مالك المنصة وGoogle Drive عبر Supabase Edge Function، مع إنشاء هيكل مجلدات واثق الأساسي مرة واحدة ومنع تكراره عند إعادة الفحص.

## ما يعمل في هذه المرحلة

- واجهة عربية RTL ومتجاوبة.
- إنشاء الاختبار عبر أربع خطوات تجريبية.
- سجل مصادر مركزي في Supabase.
- تسجيل دخول مالك المنصة.
- زر ربط Google Drive بعد تسجيل الدخول.
- OAuth بخادم وسيط، دون وضع Google Client Secret في GitHub Pages.
- حفظ Refresh Token في جدول خاص لا يصل إليه المتصفح.
- إنشاء مجلدات Drive الأساسية تلقائيًا:
  - `واثق`
  - `01_مصادر_المنصة`
  - `01_المنهج_العماني`
  - `02_اختبارات_كامبريدج`
  - `03_مصادر_عالمية`
  - `99_أرشيف_الإصدارات`
  - `02_الاختبارات_المنتجة`
- فتح مجلد واثق من المنصة.
- التحقق من المجلدات دون تكرار.
- فصل الاتصال دون حذف المجلدات أو الملفات.

## خارج نطاق Phase 0-F1

- رفع ملفات PDF فعليًا إلى Drive.
- استخراج النصوص أو الصور من PDF.
- OCR.
- تحليل الوحدات والدروس.
- توليد الأسئلة بالذكاء الاصطناعي.
- حفظ الاختبارات المنتجة في Drive.

## إعداد المرحلة

1. نفّذ SQL الموجود في:
   - `supabase/phase_0_f1_google_drive.sql`
2. أنشئ Google OAuth Client وفق:
   - `docs/PHASE_0_F1_GOOGLE_CLOUD_SETUP.md`
3. انشر Edge Function:
   - `supabase/functions/google-drive-oauth/index.ts`
4. أضف متغير GitHub:
   - `WATHIQ_GOOGLE_OAUTH_CLIENT_ID`
5. ارفع ملف Pages المحدّث:
   - `.github/workflows/pages.yml`

- يفتح Pull Request إلى `main`.
