# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## Phase 0-H1 Fix 3 — فهرس عربي متعدد الأعمدة

### ما يعمل

- يتعرف على الفهرس العربي حتى لو كان موزعًا على عمودين.
- يرتب الوحدات بحسب رقمها، لا بحسب ترتيب OCR داخل الصفحة.
- يفهم ترقيم الدروس مثل `1-1` و`٢-٣`.
- يفصل رقم الصفحة عن عنوان الدرس.
- يقبل رقم الصفحة قبل السطر أو بعده أو في سطر مستقل.
- يدمج عناوين الوحدات المتكررة داخل صفحات الكتاب.
- يمنع إنشاء وحدة جديدة لكل صفحة تحمل عنوان الوحدة نفسه.
- يحافظ على المراجعة اليدوية قبل اعتماد الهيكل.

### خارج النطاق

- استخراج نواتج التعلم والأهداف التعليمية.
- تحليل المحتوى العلمي بالذكاء الاصطناعي.
- توليد الأسئلة.

## النشر

لا توجد تغييرات على SQL أو Edge Function أو `.github/workflows/pages.yml` في هذا الإصلاح.
