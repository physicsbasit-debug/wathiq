# واثق — اختبارات علوم موثّقة من المصدر

## Phase 1-C1 — محرك الرسومات التعليمية SVG

يضيف هذا الإصدار أساسًا منضبطًا للأسئلة البصرية في واثق. لا يطلب التطبيق من نموذج الذكاء الاصطناعي إنشاء صورة حرة قد تكون جميلة ومختلة علميًا، بل يطلب **مواصفة بيانات منظمة**، يتحقق منها الخادم، ثم يرسمها واثق محليًا بصيغة SVG واضحة وقابلة للطباعة.

يبقى مرجع تقويم العلوم العُماني 2025/2026 هو الحاكم للدرجات وأنواع المفردات وأهداف التقويم، بينما تستخدم الممارسات الأسلوبية الدولية لتحسين عرض السياق والبيانات والاستقصاء.

### المرئيات المدعومة في C1

- رسم بياني خطي بمحاور ووحدات ونقاط محددة.
- رسم أعمدة بسيط ببيانات محددة.
- مخطط ضغط ثنائي الأبعاد لجسم داخل سائل.
- دائرة كهربائية مبسطة بعناصر علمية محددة.

### آلية الأمان والدقة

- Gemini يعيد `visualTarget` و`visual` وفق مخطط JSON صارم.
- الخادم يرفض نوع الرسم غير المطلوب أو القيم خارج المجال أو الدائرة الناقصة.
- المتصفح يرسم SVG من عناصر محددة مسبقًا، ولا يحقن SVG أو HTML قادمًا من النموذج.
- النصوص تهرّب قبل إدراجها داخل SVG.
- الرسوم أحادية اللون ومهيأة للطباعة.
- الرسم الواحد مشترك بين البدائل الثلاثة للمفردة، منعًا لتضخم الاستجابة واختلاف المعطيات.

### مواضع ظهور الرسم

- شاشة اختيار بديل السؤال.
- ورقة الطالب.
- نموذج الإجابة وأدلة المصدر.
- فحص حالة المسودة قبل الحفظ.

### متطلبات التشغيل

- `GEMINI_API_KEY` و`WATHIQ_APP_URL` في أسرار Supabase.
- `GEMINI_MODEL` اختياري، والقيمة الافتراضية `gemini-2.5-flash`.
- إعادة نشر وظيفة `generate-source-questions` بعد الدمج.

### الفحص

```bash
npm run check
```

لا يوجد SQL جديد، ولا أسرار جديدة، ولا حاجة إلى إعادة فهرسة الكتب.
