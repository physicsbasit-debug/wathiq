# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## المرحلة الحالية

**Phase 0-H1 Fix 1 — استخراج موثوق لهيكل الكتاب**

### ما يعمل

- رفع PDF إلى Google Drive وتسجيله في Supabase.
- استخراج النص الأصلي أو تشغيل OCR عربي عند الحاجة.
- حفظ النص في مقاطع مرتبطة بأرقام الصفحات.
- اكتشاف صفحة محتويات موثوقة فقط عند وجود عنوان واضح وتسلسل منطقي.
- رفض المعادلات والرموز والنصوص القصيرة الغامضة.
- استخراج الوحدات الصريحة فقط عند غياب فهرس موثوق.
- تحديد صفحات الفهرس يدويًا مثل `4-5` أو `4، 5`.
- استخراج الوحدات والدروس والأنشطة والمراجعات من الصفحات المحددة.
- مسح المسودة الرديئة القديمة عند إعادة الاستخراج الفاشلة.
- عرض شجرة قابلة للتعديل والحفظ والاعتماد في Supabase.

### خارج النطاق

- استخراج نواتج التعلم والأهداف التعليمية.
- تحليل المحتوى العلمي بالذكاء الاصطناعي.
- توليد الأسئلة.

## النشر

لا توجد تغييرات على SQL أو Edge Function أو `.github/workflows/pages.yml` في هذا الإصلاح.
