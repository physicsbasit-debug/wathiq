# واثق

**واثق** مولد اختبارات عربي بالكامل لمواد **علوم كامبريدج**. لا يحتاج المستخدم إلى رفع كتاب أو دليل أو بناء مكتبة مصادر قبل البدء: اختر **الصف / المرحلة** ثم **المادة** ثم **الموضوع من قائمة المنهج**، ويبدأ التأليف.

> **اسم الموضوع يكفي. حرية عالية في التأليف، صرامة عالية في المراجعة العلمية، وعربية كاملة من اليمين إلى اليسار.**

- الإصدار الحالي: **0.3.8 — Single Visual Decision Contract**.
- النطاق: **مواد العلوم فقط**.
- Cambridge Primary Science **0097**: المراحل **1–6**.
- Cambridge Lower Secondary Science **0893**: المراحل **7–9**.
- Cambridge IGCSE: الفيزياء **0625**، الكيمياء **0620**، الأحياء **0610**، العلوم المجمعة **0653**، العلوم المنسقة **0654**.

## المسار الوحيد للتوليد

```text
الصف / المرحلة + مادة العلوم + موضوع كامبريدج من القائمة
  ↓
سياق كامبريدج عالمي مناسب للمستوى
  ↓
مؤلف بالذكاء الاصطناعي يكتب بحرية
  ↓
مراجع علمي وتقويمي مستقل يستطيع إعادة الصياغة
  ↓
تحقق حتمي فقط فيما يمكن إثباته
  ↓
مرئي علمي ثنائي الأبعاد مدقق عند الحاجة
أو جدول/رسم بياني/تدريج حتمي عند الحاجة إلى دقة رقمية
  ↓
مراجعة الاختبار → وورد / بي دي إف
```


## جدول المواصفات

للصفوف 5–10، لا يترك واثق الدرجة وعدد المفردات وتوزيع أهداف التقويم للمستخدم أو للنموذج. يشتق الخطة من **وثيقة تقويم تعلم الطلبة في مواد العلوم 2025/2026** ثم يوزع المفردات والدرجات حتميًا قبل إرسال كل مفردة إلى المؤلف الذكي.

- الاختبارات القصيرة للصفوف 5–9: 15 درجة، 40% معرفة، 40% تطبيق، 20% استدلال.
- الاختبار القصير للصف 10: 10 درجات، 2 اختيار من متعدد، مفردة طويلة، والبقية قصيرة؛ 40/40/20.
- النهائي للصفوف 5–9: 40 درجة، 25–35 مفردة رسميًا، 40/40/20 في أهداف التقويم والصعوبة.
- النهائي للصف 10: 60 درجة، 30–40 مفردة، ساعتان، 10 اختيار من متعدد، مفردتان طويلتان على الأقل، 40/40/20 في أهداف التقويم والصعوبة، و8–10 درجات للاستقصاء العلمي.
- واثق يستخدم عددًا تشغيليًا ثابتًا داخل المدى الرسمي حتى تكون الخطة قابلة للتوليد وإعادة الإنتاج بصورة حتمية.

## قواعد النواة

- لا توجد منظومة رفع مصادر أو إدارة محتوى في المنتج الحالي.
- لا Google Drive ولا OAuth ولا OCR ولا شجرة كتاب ولا فهرسة موضعية.
- لا مولدات أسئلة قديمة ولا عقود صلبة تفرض السياق أو شكل السؤال على المؤلف.
- لا أهداف تعليمية اصطناعية ولا بوابة رفض تعتمد على تطابق كلمات عنوان الدرس.
- لا رسم خطي أو Overlay احتياطي للمرئيات التوضيحية؛ المرئي المطلوب ثنائي الأبعاد ومدقق علميًا.
- القرار البصري واحد: إما `none` أو نوع مرئي فعلي. المخططات العلمية المنظمة تُرسم داخل واثق فورًا، و`context_scene` وحده يحتاج أصل صورة 2D مدققًا قبل الاعتماد والتصدير.
- ورقة الطالب لا تعرض رسائل فشل أو انتظار للأصول البصرية، ولا يظهر فيها الشرح العلمي أو ملاحظات المراجع.
- محقق علمي حتمي يمنع تناقضات فيزيائية قابلة للكشف يقينًا قبل الاعتماد، مع بقاء المراجع الذكي مسؤولًا عن الحكم العلمي الأوسع.
- الجداول والرسوم البيانية والتدريجات ذات القيم الدقيقة تبقى حتمية.
- لا تظهر رسالة مزود خام بالإنجليزية للمستخدم.
- الواجهة والتقارير والتصدير عربية واتجاهها من اليمين إلى اليسار.
- `npm run legacy:check` يفشل إذا عادت أحفورة محظورة.
- `npm run ui:check` يفشل إذا كُسرت العربية أو RTL أو تسربت واجهة إنجليزية معروفة.

## الفحص

```bash
npm install --no-package-lock --no-audit --no-fund
npm run check
```

يشمل الفحص: نظافة المستودع، منع الأحافير، العربية وRTL، بناء TypeScript، واختبارات السلوك الحالي فقط.
