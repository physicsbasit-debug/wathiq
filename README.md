# واثق — اختبارات علوم موثّقة من المصدر

## Phase 1-C2 — تجميع الاختبار واعتماده وتصديره

يحوّل هذا الإصدار ناتج التوليد من مسودة للمعاينة إلى اختبار قابل للمراجعة والاعتماد والتسليم، مع الحفاظ على مرجع تقويم العلوم العُماني 2025/2026 بوصفه الحاكم للدرجات وأنواع المفردات وأهداف التقويم.

### ما يضيفه C2

- توزيع مفردات الاختيار من متعدد بين الأسئلة الإنشائية متى كان الفصل ممكنًا، بدل تجميعها متتالية.
- وضع المتن والرسم قبل الأجزاء التي تعتمد عليه، وعدم تفكيك السؤال المركب.
- تنويع الرسومات الحتمية محليًا لكل مفردة بصرية من دون طلب Gemini إضافي.
- دعم مخططات الضغط المتنوعة، والدوائر البسيطة، والرسوم الخطية، ورسوم الأعمدة.
- فحص اكتمال الدرجات والاختيارات والمصدر ونموذج التصحيح والعناصر البصرية قبل الاعتماد.
- زر **اعتماد الاختبار** يقفل التعديل ويثبت وقت الاعتماد.
- زر **إلغاء الاعتماد للتعديل** يعيد الاختبار إلى المراجعة من دون حذف الأسئلة.
- تصدير ورقة الطالب ونموذج الإجابة إلى ملف Word متوافق بصيغة `.doc`.
- فتح نسخة طباعة A4 مخصصة يمكن حفظها PDF من نافذة الطباعة في المتصفح.

## Phase 1-C1 — محرك الرسومات التعليمية SVG

### ما بقي من C1

- Gemini لا يرسم SVG ولا يعيد مواصفته في JSON.
- الخادم يبني مواصفة SVG حتمية وآمنة (`fixedVisual`) ثم يصوغ Gemini السؤال حوله.
- الرسوم تهرب النصوص، وتتحقق من المحاور والقيم والمكونات، وتجهز للطباعة بالأبيض والأسود.
- لا تضيع الأسئلة الصحيحة بسبب مواصفة بصرية ناقصة.

### النشر

- يلزم إعادة نشر وظيفة `generate-source-questions` بعد الدمج لأن C2 يضيف تنويعًا حتميًا للرسومات الجديدة.
- لا يوجد SQL جديد.
- لا توجد أسرار جديدة.
- لا حاجة إلى إعادة فهرسة الكتب.

### الفحص

```bash
npm run check
```

### ملاحظة الحزمة

حزمة الملفات المعدلة في التسليم تراكمية فوق نسخة `main` المرفوعة بإصدار 0.0.34، وقد اختبرت أيضًا فوق C1 Fix 2 بإصدار 0.0.36 لتجنب أي تراجع عند اختلاف النسخة الفعلية في المستودع.
