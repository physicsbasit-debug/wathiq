# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## المرحلة الحالية

**Phase 0-H1 — استخراج هيكل الكتاب من الفهرس**

### ما يعمل

- رفع PDF إلى Google Drive وتسجيله في Supabase.
- استخراج النص الأصلي أو تشغيل OCR عربي عند الحاجة.
- حفظ النص في مقاطع مرتبطة بأرقام الصفحات.
- اكتشاف صفحات المحتويات تلقائيًا.
- استخراج الوحدات والدروس والموضوعات والأنشطة والمراجعات والأسئلة.
- حذف أرقام الصفحات من نص العنوان وحفظها في حقول مستقلة.
- منع تكرار الوحدة والعنوان نفسه.
- استبعاد حقوق الطباعة والمقدمات من الهيكل التعليمي.
- عرض شجرة قابلة للتعديل وإعادة الترتيب والحذف والإضافة.
- حفظ مسودة الهيكل أو اعتمادها في Supabase.

### خارج النطاق

- استخراج نواتج التعلم والأهداف التعليمية، ويأتي في Phase 0-H2.
- تحليل المحتوى العلمي بالذكاء الاصطناعي.
- توليد الأسئلة.
- إتاحة الهيكل للمعلم قبل اعتماد مدير المحتوى.

## نشر Phase 0-H1

1. ارفع حزمة الملفات المعدلة إلى فرع مستقل.
2. انتظر نجاح GitHub Actions.
3. شغّل `supabase/phase_0_h1_source_structure.sql` في SQL Editor.
4. ادمج الطلب وانشر GitHub Pages.
5. افتح تفاصيل كتاب مفهرس واضغط «استخراج هيكل الكتاب».
6. راجع الوحدات والدروس، ثم احفظ المسودة أو اعتمد الهيكل.

ملف `.github/workflows/pages.yml` لم يتغير في هذه المرحلة.
