# واثق — اختبارات علوم موثقة بالمنهج ومرئيات علمية منضبطة

## Phase 1-D1 — النظام الهجين المنضبط للمرئيات العلمية

الإصدار الحالي: **`0.0.47`**  
إصدار عقد التوليد: **`source-grounded-policy-ai-15-controlled-hybrid-visuals`**

تبقي هذه المرحلة الرسوم الحتمية الدقيقة عمودًا فقريًا للاختبار، وتضيف صورًا تعليمية ثنائية الأبعاد فقط للمشاهد السياقية الآمنة. لا يُسمح للصورة المولدة بحمل القيم أو الأسهم أو التسميات التي يعتمد عليها الحل؛ تظل هذه العناصر تحت سيطرة محرك واثق القابل للتحقق.

### قاعدة الاختيار

- **الرسم الحتمي:** مخططات القوى، الدوائر، الأشعة، تدريجات الأجهزة، الجداول، الرسوم البيانية، القيم، الوحدات، والأسهم.
- **الصورة ثنائية الأبعاد:** مشاهد توضيحية محدودة مثل دلك جسم وظهور أثر الكهرباء الساكنة أو جسم مغمور في سائل، بعد فحص علمي مستقل.
- **خطة الرجوع:** يبقى SVG الحتمي خلف الصورة دائمًا، ويظهر تلقائيًا إذا فشل التوليد أو الفحص أو التخزين أو تحميل الصورة في التصدير.

### ما أضافته المرحلة

- خيار **تحسين المشاهد المؤهلة بصور 2D مدققة**، مفعّل افتراضيًا وقابل للتعطيل دون حذف الرسوم الحالية.
- توليد تلقائي متسلسل لثلاثة مشاهد مؤهلة كحد أقصى لتقليل الضغط والتكلفة.
- زر لإعادة توليد الصورة، وزر للعودة إلى الرسم الحتمي فقط.
- منع توليد صور حرة للمخططات التي تؤثر في صحة الحل.
- منع النصوص والأرقام والوحدات والأسهم والرموز العلمية داخل الصورة المولدة.
- فحص بصري علمي منظم قبل قبول الصورة.
- حفظ الصورة المقبولة في Supabase Storage وربطها بالمسودة بدل تخزين Base64 داخلها.
- تصدير Word وPDF مع الصورة المدققة، مع رجوع تلقائي إلى SVG عند تعذر جلبها.
- توافق المسودات السابقة وترقيتها دون حذف الأسئلة المكتملة.

### إصلاحات مستفادة من الاختبار الفعلي

- إظهار القيم والوحدات في الرسوم الحسابية عند طلب الحساب.
- إزالة العنوان المركب المضلل من أعلى الرسم.
- تقليل ارتفاع المرئيات والفراغات في Word وPDF.
- إخفاء وصف الرسم الطويل في ورقة الطالب مع بقائه في واجهة المراجعة.
- استبدال تذييل الصفحة الثابت الخاطئ بعبارة **انتهت الأسئلة**.

## الأساس الموروث

يبقى **Phase 1-C1** ومبدأ **مواصفة SVG حتمية وآمنة** أساس محرك الرسومات، وتستمر توسعات C3 وC4 كما هي. Phase 1-D1 تضيف طبقة صور اختيارية ومدققة فوق هذا الأساس ولا تستبدله.

## النشر

تعدل المرحلة وظيفة Supabase التالية:

```text
supabase/functions/generate-source-questions/index.ts
```

بعد دمج الفرع يجب إعادة نشر الوظيفة. لا يلزم SQL أو إعادة فهرسة أو سر جديد. يستخدم محرك الصور مفتاح Gemini الموجود، ويمكن تغيير النموذج اختياريًا عبر `GEMINI_IMAGE_MODEL`، بينما القيمة الافتراضية موجودة في الكود.

ينشئ واثق تلقائيًا حاوية عامة باسم:

```text
wathiq-question-visuals
```

تُستخدم للصور التعليمية المولدة فقط، ولا ينبغي رفع بيانات شخصية إليها.

## ملاحظة قبول التشغيل

تم اختبار البناء، العقود، تحليل الاستجابة، قواعد الأهلية، الفحص، التخزين، الرجوع الحتمي، والتصدير آليًا. لم يُنفذ اتصال حي من بيئة التطوير بمفتاح Gemini وحساب Supabase الفعلي؛ لذلك يعد أول توليد صورة بعد النشر اختبار قبول إلزاميًا قبل اعتماد المرحلة نهائيًا.
