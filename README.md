# واثق

منصة عربية مبسطة لإنشاء الاختبارات القصيرة في مواد العلوم.

## المرحلة الحالية

**Phase 0-D — سجل المصادر المنظم**

تثبت هذه المرحلة طريقة تسجيل المصادر وتتبعها ونقل سجلها قبل ربط Google Drive والفهرسة الإنتاجية.

## ما يعمل حاليًا

- واجهة عربية RTL ومتجاوبة.
- رحلة المعلم التجريبية عبر أربع خطوات.
- إدارة ملفات PDF والروابط كسجلات محلية.
- رقم فهرسة تلقائي لكل مصدر.
- تحديد جهة المصدر تلقائيًا.
- كشف المصدر المكرر ومنع إضافته.
- تفاصيل كاملة لكل مصدر.
- الأرشفة والاستعادة.
- تصدير سجل المصادر إلى JSON.
- استيراد سجل واثق ودمجه دون تكرار.
- ترقية بيانات Phase 0-C المحلية تلقائيًا.

## ما لا يعمل عمدًا بعد

- رفع PDF الفعلي إلى Google Drive.
- جلب صفحات المواقع.
- استخراج النصوص والصور والجداول.
- الفهرسة العلمية الحقيقية.
- توليد الأسئلة بالذكاء الاصطناعي.
- تصدير Word وPDF الحقيقي للاختبارات.

## العمل عبر GitHub

كل مرحلة في فرع مستقل، ثم Pull Request إلى `main`، ولا يتم الدمج قبل نجاح GitHub Actions والمراجعة البصرية.
