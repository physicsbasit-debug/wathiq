# واثق — اختبارات علوم موثّقة من عدة دروس

## Phase 1-B4 — عناوين الاختبارات وتثبيت التاريخ

أصبح مسار الاختبار القصير الرسمي يقبل **من درسين إلى خمسة دروس** بدل حقل موضوع واحد. يطابق واثق كل درس بصفحات الكتاب المفهرس، ثم يبني خطة الاختبار الرسمية ويولد أسئلتها على دفعات صغيرة.

### ما يعمل في هذا الإصدار

- إدخال 2-5 دروس بصيغة واضحة، مثل `1-1 الضغط` و`1-2 الضغط في السوائل`.
- منع الدروس المكررة ومنع الانتقال إذا لم يرتبط أحد الدروس بصفحات المصدر.
- عرض صفحات كل درس قبل التوليد.
- توزيع مفردات الخطة الرسمية على جميع الدروس المختارة.
- توليد مفردتين كحد أقصى في كل دفعة لتقليل التأخير وحجم استجابة Gemini.
- حفظ الدفعات المكتملة، ثم استكمال الباقي فقط عند إعادة المحاولة.
- قراءة استجابة Gemini المنظمة مع معالجة أغلفة Markdown والنص الزائد ورسائل JSON المبتور.
- استمرار تطبيق مرجع تقويم العلوم 2025/2026 وقالب الاختبار القصير الرسمي لكل صف.

### متطلبات التشغيل

- إعداد Supabase الحالي وتسجيل دخول مالك المنصة.
- وجود `GEMINI_API_KEY` و`WATHIQ_APP_URL` في أسرار Supabase.
- نشر الوظيفة `generate-source-questions` من محرر Supabase بعد دمج التعديلات.

### الفحص

```bash
npm run check
```

لا يوجد SQL جديد، ولا حاجة لإعادة فهرسة المصادر الجاهزة.
