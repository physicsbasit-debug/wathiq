# واثق

منصة عربية لإنشاء الاختبارات القصيرة في مواد العلوم اعتمادًا على مصادر مركزية معتمدة.

## المرحلة الحالية

**Phase 0-G Fix 2B — OCR عربي فعلي**

### ما يعمل

- رفع PDF إلى Google Drive وتسجيله في Supabase.
- استخراج طبقة النص الأصلية وفحص جودتها.
- رفض النص العربي المشوه.
- تشغيل OCR عربي عبر Google Cloud Vision للملفات المصورة أو المشوهة.
- حفظ كل صفحة OCR فورًا واستكمال الناقص بعد الانقطاع.
- فهرسة النص فقط بعد اجتياز بوابة الجودة.

### خارج النطاق

- تحليل الوحدات والدروس بالذكاء الاصطناعي.
- توليد الأسئلة.
- OCR للخط اليدوي.
- مراجعة تربوية تلقائية للعناوين المستخرجة.

راجع ملفات `docs/PHASE_0_G_FIX2B_*` للنشر والقبول.
