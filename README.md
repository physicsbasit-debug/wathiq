# واثق — اختبارات علوم موثقة بالمنهج وإثراء علمي منضبط

## Phase 1-C4 — الإثراء المنهجي الموثوق واستقرار التوليد

يبقى **الكتاب المدرسي وصفحات الدرس المختارة المرجع الحاكم** للسؤال والإجابة ونموذج التصحيح. ويمكن للمعلم تفعيل خيار واحد بسيط يسمح لواثق بالبحث عن سياقات وبيانات وتجارب وتطبيقات من مصادر علمية رسمية أو جامعية موثوقة، من غير تحويل المعرفة الخارجية إلى متطلب على الطالب.

### ما أضافته المرحلة

- خيار مرئي واحد: **الإثراء من مصادر علمية رسمية وموثوقة**.
- بحث موثق مستقل عبر Google Search Grounding قبل التوليد المنظم.
- قبول الجمل المسندة فقط إلى نطاقات حكومية أو جامعية أو منظمات علمية معروفة.
- حفظ أثر الإثراء داخل السؤال: النص المساند، عنوان المصدر، والرابط.
- تجاهل الإثراء تلقائيًا إذا لم يوجد مصدر موثوق مناسب، ثم متابعة التوليد من الكتاب وحده.
- عدم اعتبار ذاكرة النموذج أو صياغته مصدرًا علميًا.

### معالجة الأخطاء التي ظهرت عمليًا

- إعادة محاولة أخطاء الضغط المؤقت `429/503` والمهلات تلقائيًا حتى ثلاث محاولات بتأخير متدرج وعشوائي بسيط.
- تعريب رسالة الضغط المرتفع بدل عرض رسالة Gemini الإنجليزية للمستخدم.
- عدم تكرار دورة النقل مرة ثانية بعد استنفاد المحاولات الثلاث.
- استمرار حفظ الدفعات المكتملة، ثم إكمال المفردات الباقية فقط عند الضغط على **التالي**.
- فحص ارتباط السؤال أولًا بالمقطع المختار، ثم بمحتوى مرجع الدرس كاملًا إذا كان المقطع أضيق من السؤال.
- قبول الارتباط الصحيح بالمرجع الكامل مع وسم السؤال للمراجعة، مع استمرار رفض السؤال الغريب عن المرجع.
- ترقية مسودات Phase 1-C3 المكتملة إلى العقد الجديد دون حذف أسئلتها.
- تغيير خيار الإثراء لا يمسح الأسئلة المكتملة؛ يطبق فقط على المفردات الجديدة أو المعاد توليدها.

### المرئيات السابقة محفوظة

هذه المرحلة مبنية على **Phase 1-C1** ومبدأ **مواصفة SVG حتمية وآمنة**، ثم على توسعات Phase 1-C3. تستمر جميع المرئيات الحتمية: الرسوم الخطية والأعمدة والجداول وأجهزة القياس والأشعة والقوى والعمليات والضغط والدوائر والكهرباء الساكنة. لا توجد صور حرة مولدة، ولا تغيير في تصدير Word أو PDF.
