# واثق

**واثق** منصة لإعداد اختبارات **مواد العلوم** اعتمادًا على مصادر منهجية موثقة، مع بناء خطة تقويم قبل التوليد، وربط كل مفردة بمصدرها، والتحقق العلمي والمرئي، ثم المراجعة والتصدير إلى Word/PDF.

- الإصدار الحالي: **0.0.68**
- الحالة المعمارية: **D4 End-to-End Repair + Phase 3 Progressive 2D Reliability**
- نطاق العمل الحالي: **العلوم فقط**
- خط الأساس المحلي: **501 اختبارًا ناجحًا، 0 فشل**
- القبول الحي: **نجح الاستكمال بعد Refresh وحفظ المفردات؛ v0.0.68 يغلق انحراف النشر الذي أبقى بعض الملفات الداخلية على منطق أقدم، ويحتاج إعادة قبول حي قصيرة بعد نشر الواجهة ووظيفتي Edge**

## التدفق الإنتاجي الحالي

```text
مصادر موثقة
  ↓
اختيار الصف/المادة/الدروس
  ↓
خطة تقويم حتمية
  ↓
Assessment Blueprint + Item Contracts
  ↓
Durable Generation Run
  ↓
عاملان للمفردات بحد افتراضي 2
  ↓
Grounding → Generation → Normalization → Validation
  ↓
حفظ كل مفردة جاهزة خادميًا ودمجها تدريجيًا
  ↓
الأصول البصرية الدائمة عند الحاجة
  ↓
مراجعة عامة
  ↓
اعتماد وتصدير Word/PDF
```

## البنية

- `src/assessment-engine/` — العقود المشتركة، البصمات، المخطط، التطبيع، التحقق والمراجعة العامة.
- `src/assessment-generation-*.ts` — التوليد التدريجي، المنسق، العميل والعامل.
- `src/question-visual.ts` و`src/visual-jobs.ts` — تمثيلات علمية منظمة وأصول 2D دائمة؛ لا يُعرض رسم خطي احتياطي للأنواع التي تتطلب أصل 2D.
- `src/source-*.ts` — هوية المصادر، الاسترجاع، الفهرسة والتخزين المركزي.
- `src/exam-export.ts` — Word/PDF.
- `supabase/` — SQL التشغيلي وEdge Functions.
- `tests/` — اختبارات الانحدار والعقود الحالية.
- `references/` — المراجع الرسمية التي يحتاجها المشروع.

## التشغيل المحلي

```bash
npm install --no-audit --no-fund
npm run repo:check
npm run check
npm run dev
```

> `dist/` ناتج بناء فقط، ولا يُحفظ في المستودع. GitHub Actions يبنيه تلقائيًا للاختبارات وGitHub Pages.
