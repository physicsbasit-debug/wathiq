# Phase 0-H1 Fix 3 — استخراج الفهرس العربي متعدد الأعمدة

## المشكلة

الفهرس الأصلي موزع على عمودين، بينما النص المسطح قد يقرأ العمود الأيسر قبل الأيمن أو يخلط بينهما. كما كانت عناوين الوحدات داخل صفحات المحتوى تتكرر مع رقم الصفحة، فتتحول الوحدة الواحدة إلى وحدات عديدة.

## الحل

- استخراج رقم الوحدة من العنوان العربي: الأولى، الثانية، … الحادية عشرة.
- استخراج رمز الدرس من النمط `رقم الوحدة-رقم الدرس`.
- تجميع الدروس تحت وحدتها اعتمادًا على الرمز، لا ترتيب OCR.
- ترتيب الوحدات رقميًا بعد الاستخراج.
- فصل رقم الصفحة عن العنوان.
- دعم رقم الصفحة في أول السطر أو آخره أو في سطر منفصل.
- دمج عناوين الوحدة المتكررة داخل صفحات الكتاب.
- اعتبار الصفحة فهرسًا موثوقًا عند وجود كثافة كافية من الوحدات والدروس المرقمة، حتى لو لم يظهر عنوان «المحتويات» بوضوح.
