# Phase 1-C2 Fix 6 — Page-Scoped Lesson Evidence

## المشكلة
كان الخادم يرفض مرجعًا صحيحًا من صفحات الدرس إذا لم يتكرر عنوان الدرس حرفيًا داخل المقطع النصي. صفحات الشرح الواقعة بعد عنوان الدرس قد تحتوي المحتوى العلمي دون إعادة الاسم الكامل، فيظهر الخطأ: «المرجع المختار لا يثبت ارتباط السؤال بالدرس المحدد».

## الحل
أصبح كل مرجع يُرسل إلى وظيفة التوليد مع بيانات نطاقه:

- `sourceId`
- `lessonTopic`
- `lessonScopeMode`
- `lessonPageFrom`
- `lessonPageTo`

تستخدم الوظيفة أربعة أوضاع:

1. `page-range`: المقطع يتقاطع مع نطاق صفحات الدرس الموثق.
2. `page-neighborhood`: المقطع يقع ضمن هامش ثلاث صفحات حول النطاق لمعالجة حدود التقسيم.
3. `strict-title-fallback`: بحث احتياطي خارج النطاق، ويبقى مشروطًا بتطابق قوي مع عنوان الدرس.
4. `legacy-title`: توافق خلفي مع المراجع القديمة أو الاختبارات التاريخية.

## قواعد الأمان

- يجب أن يطابق `lessonTopic` درس مفردة الخطة.
- يجب أن يكون المقطع داخل نطاق الدرس أو هامشه المسموح.
- البحث الاحتياطي خارج الصفحات لا يقبل إلا عند تطابق عنوان الدرس مع النص.
- يبقى فحص ارتباط نص السؤال بدليل المصدر قائمًا بعد إثبات نطاق الدرس.
- لا يتغير إصدار تخزين التوليد، لذلك تبقى المفردات المكتملة في المسودة.

## ما لم يتغير

- لا إعادة فهرسة.
- لا SQL أو أسرار جديدة.
- لا تغيير لجداول المواصفات.
- لا تغيير لمحرك الرسومات أو نموذج التصحيح.
