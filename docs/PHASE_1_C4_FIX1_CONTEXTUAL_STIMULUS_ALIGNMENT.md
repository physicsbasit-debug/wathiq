# Phase 1-C4 Fix 1 — Contextual Stimulus Alignment

## سبب الإصلاح

ظهر أثناء التشغيل أن إحدى مفردات الأسئلة البصرية رُفضت برسالة تفيد بعدم وجود متن أو بيانات كافية، رغم أن الرسم أو الجدول الحتمي المرفق كان يحمل البيانات المطلوبة فعليًا.

كان التحقق القديم يشترط وجود نص داخل `stimulus` لكل سؤال سياقي أو حسابي أو بياني أو استقصائي، ثم يتحقق لاحقًا من الرسم. هذا خلق تعارضًا مع محرك المرئيات المتقدمة: قد يكون الرسم نفسه هو المتن العلمي الكامل، ويشير نص السؤال إليه بوضوح، بينما يبقى `stimulus` فارغًا بصورة صحيحة.

## التعديل المعتمد

1. أصبح التحقق يقيس السؤال كاملًا، لا حقل `stimulus` وحده.
2. يقبل `stimulus` فارغًا عندما:
   - يكون للسؤال رسم أو جدول أو تدريج حتمي؛
   - ويشير نص السؤال صراحة إلى الشكل أو الرسم أو المخطط أو الجدول أو التدريج أو الجهاز أو البيانات الممثلة.
3. يقبل السياق المضمن داخل نص السؤال نفسه إذا كان كافيًا ومناسبًا لنمط السؤال.
4. يستمر رفض السؤال القصير المبهم الذي لا يحتوي متنًا ولا رسمًا ولا بيانات فعلية.
5. توسعت كلمات الارتباط بالمرئي لتشمل الجداول والتدريجات والأجهزة، لا الرسوم والمخططات فقط.

1. يعيد واثق توليد كل مفردة منفردة.

3. إذا بقيت المفردة الأخرى معطوبة، تظهر النتيجة مثل `5 من 6` بدل خسارة المفردتين معًا.
