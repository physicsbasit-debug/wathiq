# Phase 1-B Fix 1 — اعتماد Gemini كمزود التوليد

## سبب الإصلاح

كانت النسخة الأولى من Phase 1-B تستدعي OpenAI رغم أن مزود الذكاء الاصطناعي المعتمد في واثق هو Gemini. هذا الإصلاح يستبدل المزود فقط دون تغيير واجهة المستخدم أو منطق الاسترجاع أو التحقق من الاستناد للمصدر.

## التغييرات

- استبدال `OPENAI_API_KEY` بـ `GEMINI_API_KEY`.
- إضافة `GEMINI_MODEL` اختياريًا، والقيمة الافتراضية `gemini-2.5-flash`.
- استخدام Gemini Interactions API عبر الخادم فقط.
- إرسال مخطط JSON منظم والتحقق محليًا من النتيجة كما كان سابقًا.
- تعطيل تخزين التفاعل لدى المزود باستخدام `store: false`.
- الإبقاء على المصادقة عبر جلسة Supabase وعلى ضوابط الدليل النصي الحرفي.

## النشر

بعد دمج الإصلاح، أضف سر `GEMINI_API_KEY` إلى Supabase ثم أعد نشر الوظيفة `generate-source-questions`. لا حاجة إلى أي سر باسم `OPENAI_API_KEY`.
