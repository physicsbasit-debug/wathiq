# نشر Phase 0-F2 من الواجهات فقط

## أولًا: GitHub

1. أنشئ فرعًا من `main` باسم `feat/phase-0-f2-pdf-upload`.
2. ارفع محتويات حزمة الملفات المعدلة فقط إلى الفرع.
3. استخدم رسالة الالتزام:
   `feat: رفع مصادر PDF فعليًا إلى Google Drive في Phase 0-F2`
4. افتح Pull Request ولا تدمجه قبل نجاح الفحص.

## ثانيًا: Supabase SQL

1. افتح مشروع `wathiq-production`.
2. افتح `SQL Editor` ثم استعلامًا جديدًا.
3. الصق محتوى `supabase/phase_0_f2_source_uploads.sql` كاملًا.
4. اضغط `Run` ووافق على التحذير إن ظهر.
5. النتيجة المطلوبة: `Success. No rows returned`.

## ثالثًا: Edge Function

1. افتح `Edge Functions` ثم `google-drive-oauth`.
2. افتح محرر الكود.
3. استبدل الكود كاملًا بمحتوى `supabase/functions/google-drive-oauth/index.ts`.
4. انشر الدالة.
5. افتح إعدادات الدالة وتأكد أن `Verify JWT with legacy secret` مغلق.

## رابعًا: الدمج والنشر

1. بعد نجاح GitHub Actions ونشر Edge Function، ادمج Pull Request.
2. انتظر نجاح `نشر معاينة واثق` على `main`.
3. افتح المنصة مع تحديث قوي للصفحة.

## اختبار القبول

1. سجّل دخول المالك.
2. تأكد أن Drive متصل.
3. أضف PDF تجريبيًا وحدد الصف والمادة والنوع.
4. راقب التقدم حتى 100%.
5. افتح الملف من رابط Drive.
6. حدّث الصفحة وتأكد أن المصدر موجود.
7. أرشف المصدر وتأكد من انتقال الملف إلى الأرشيف.
8. استعد المصدر وتأكد من رجوعه إلى مجلده الأصلي.
