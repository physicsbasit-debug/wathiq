# تشغيل واثق 0.3.0

## إنشاء اختبار

1. سجّل الدخول إلى واثق.
2. افتح «اختبار جديد».
3. اختر برنامج كامبريدج.
4. اختر المرحلة أو السيلابس ومادة العلوم.
5. اكتب اسم الموضوع أو الموضوعات.
6. اضبط الدرجة والزمن ونمط الاختبار إذا رغبت.
7. ابدأ التوليد وراجع المفردات المكتملة تدريجيًا.
8. اعتمد الاختبار ثم صدّر نسخة الطالب ونموذج الإجابة.

**لا توجد خطوة رفع كتاب أو دليل أو مصدر. اسم الموضوع والمرحلة/السيلابس هما مدخل المعرفة الأساسي.**

## المرئيات

- المرئي التوضيحي يولد كأصل علمي ثنائي الأبعاد ثم يراجع قبل الاعتماد.
- لا يوجد رسم خطي بديل إذا فشل توليد الصورة.
- الجداول والرسوم البيانية والتدريجات الرقمية تبقى حتمية لحماية القيم والمحاور.

## عند تعطل خدمة خارجية

تظهر للمستخدم رسالة عربية مفهومة. لا تمسح المفردات المكتملة، ولا تعيد الاختبار كله من الصفر بسبب تعثر مفردة واحدة أو أصل بصري واحد.
