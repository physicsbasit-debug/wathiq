# تشغيل واثق

## إنشاء اختبار دون أي ملفات

1. افتح **اختبار جديد**.
2. اختر Cambridge Primary أو Lower Secondary أو IGCSE.
3. اختر Stage والمادة عند الحاجة.
4. اكتب من موضوع واحد إلى خمسة موضوعات.
5. اضبط الزمن والدرجة وعدد أنواع الأسئلة، ثم ابدأ التوليد.

هذا هو المسار الأساسي. لا تحتاج إلى كتاب أو دليل معلم أو فهرسة مسبقة.

## المصادر الاختيارية

إذا أردت تخصيص الاختبار بكتاب أو دليل محدد:

1. افتح **مصادر اختيارية**.
2. أضف PDF.
3. اختر Stage/IGCSE والمادة ونوع المصدر.
4. يفهرس واثق النص مباشرة ويستخدم OCR فقط عند الحاجة.
5. في إعداد الاختبار يمكنك اختيار **استخدام المصادر المتاحة**.

الإصدار والسنة والفصل الدراسي ليست متطلبات إدخال.

## فشل مفردة

- المفردات المكتملة تبقى محفوظة.
- أعد المفردة الفاشلة وحدها.
- أخطاء الضغط المؤقت في النموذج تستخدم retry/backoff ولا تعيد الاختبار كاملًا.

## المرئيات

- البيانات الرقمية الدقيقة تظهر حتميًا.
- المرئيات التوضيحية تنشأ كأصل 2D وتراجع علميًا قبل اعتمادها.
- فشل 2D يبقى فشلًا واضحًا؛ لا يظهر رسم خطي بديل.

## فحص محلي

```bash
npm install --no-audit --no-fund

```
