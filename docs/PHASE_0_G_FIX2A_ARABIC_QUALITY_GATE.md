# Phase 0-G Fix 2A — بوابة جودة النص العربي

## المشكلة

كان معيار Phase 0-G يعتمد أساسًا على كمية النص المستخرج. بعض ملفات PDF العربية تحتوي طبقة محارف داخلية مشوهة تنتج آلاف الحروف العربية غير المقروءة؛ لذلك كانت تمر بوصفها نصًا مكتملًا وتُحفظ في الفهرس.

## الحل

أضيف فحص جودة قبل إنشاء المقاطع، يجمع بين:

- نسبة الكلمات العربية الشائعة داخل النص.
- متوسط طول الكلمات ونسبة الكلمات الطويلة بصورة غير طبيعية.
- نسبة الكلمات ذات الحرف الواحد.
- تركّز الحروف الأكثر تكرارًا.
- فحص الصفحات منفردة حتى لا يخفي عنوان سليم صفحات تالفة.

لا يعتمد القرار على مؤشر منفرد.

## السلوك

عند فشل الجودة:

1. لا تُنشأ أي صفوف في `source_chunks`.
2. تُحذف المقاطع القديمة إن كانت موجودة.
3. تصبح حالة المصدر `يحتاج مراجعة`.
4. تصبح حالة الاستخراج `يحتاج OCR`.
5. تُحذف المعاينة والعناوين القديمة حتى لا تظهر مادة مشوهة للمستخدم.
6. يظهر تفسير واضح بأن طبقة النص داخل PDF غير صالحة.

## التوافق مع المصادر القديمة

بعد تسجيل الدخول والمزامنة يفحص واثق المعاينات القديمة عالية الاشتباه. إذا ثبت أن نصًا سبق وسمه `مكتمل` مشوه، تُلغى فهرسته مركزيًا تلقائيًا مرة واحدة.

## خارج النطاق

- تنفيذ OCR العربي.
- تصحيح النص المشوه تخمينيًا.
- اعتماد العناوين تربويًا.
