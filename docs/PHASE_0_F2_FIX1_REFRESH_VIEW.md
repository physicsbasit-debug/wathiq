# Phase 0-F2 Fix 1 — تثبيت الصفحة النشطة بعد التحديث

## المشكلة

عند تحديث المتصفح تحديثًا قسريًا من صفحة إدارة المحتوى، كان التطبيق يبدأ دائمًا من الصفحة الرئيسية رغم بقاء بيانات المصادر محفوظة.

## الإصلاح

- إضافة مسارات Hash آمنة ومتوافقة مع GitHub Pages.
- حفظ الصفحة النشطة في `sessionStorage` كخيار احتياطي.
- استعادة صفحة إدارة المحتوى بعد `Ctrl + F5`.
- دعم زري الرجوع والتقدم في المتصفح.
- إعادة مستخدم OAuth إلى صفحة إدارة المحتوى بعد اكتمال ربط Google Drive.

## خارج النطاق

لا تغيير في رفع PDF أو Supabase أو Google Drive أو SQL أو Edge Function.
