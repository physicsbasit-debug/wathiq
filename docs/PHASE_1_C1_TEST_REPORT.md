## حالات الاختبار البصرية

- رسم خطي بمحورين ووحدات ونقاط داخل المجال.
- رفض نقطة خارج مجال المحور.
- رسم أعمدة مع عدد قيم مطابق للفئات.
- رفض اختلاف عدد القيم والفئات.
- مخطط ضغط بقيم نسبية صحيحة.
- دائرة كهربائية تحتوي بطارية وحملًا.
- رفض دائرة بلا بطارية أو بلا حمل.
- تهريب نصوص مثل `<script>` وعدم إدراجها كعناصر SVG.
- فصل مفردات التطبيق والاستدلال والأسئلة الثقيلة في طلبات منفردة لتقليل المهلة عند توليد الرسم.

## حدود التحقق

لم يُختبر اتصال حي بمفتاح Gemini أو مشروع Supabase الخاص بالمستخدم؛ الاختبار الحي الأخير يتم بعد إعادة نشر Edge Function. كذلك لا تشمل C1 الرسومات التشريحية التفصيلية أو أجهزة الكيمياء المركبة أو الصور الواقعية.

## أثر النشر

- يجب إعادة نشر `supabase/functions/generate-source-questions/index.ts` عبر محرر Supabase.
- لا SQL جديد.
- لا سر جديد.
- لا حاجة إلى إعادة فهرسة المصادر.
