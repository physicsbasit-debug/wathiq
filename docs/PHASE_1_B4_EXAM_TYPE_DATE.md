# Phase 1-B4 — نوع الاختبار وتثبيت التاريخ

## ما تغير

- أصبح عنوان الاختبار قائمة منسدلة بثلاثة خيارات:
  - الاختبار القصير الأول
  - الاختبار القصير الثاني
  - الاختبار النهائي
- الاختباران القصيران يستخدمان قالب الاختبار القصير الرسمي للصف المختار.
- الاختبار النهائي يستخدم مواصفات امتحان نهاية الفصل الرسمية:
  - الصفوف 5-9: 40 درجة، 25-35 مفردة، ساعة ونصف.
  - الصف 10: 60 درجة، 30-40 مفردة، ساعتان.
- يملأ تاريخ اليوم تلقائيًا في المسودة الجديدة.
- يلتقط واثق تغيير التاريخ عبر input وchange وblur، ويعيد قراءة الحقل مباشرة قبل الانتقال.

## النشر

بعد دمج الفرع في `main`:

1. انتظر نجاح GitHub Actions ونشر GitHub Pages.
2. انسخ ملف `supabase/functions/generate-source-questions/index.ts` من GitHub عبر Raw.
3. الصقه في وظيفة `generate-source-questions` داخل محرر Supabase.
4. اضغط Deploy function.
5. افتح واثق ونفذ تحديثًا قويًا `Ctrl + F5`.

## اختبار القبول السريع

1. اختر الصف 10 والفيزياء وأدخل درسين إلى خمسة.
2. في الإعداد اختر كل عنوان من القائمة وتأكد أن القالب يتغير.
3. غيّر التاريخ ثم اضغط التالي مباشرة.
4. يجب ألا تظهر رسالة «اختر تاريخ الاختبار» بعد اختيار تاريخ صالح.
