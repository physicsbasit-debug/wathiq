# نشر Phase 1-B2 من GitHub وSupabase

## أولًا: GitHub

1. أنشئ الفرع:
   `phase-1b2-official-assessment-policy`
2. ارفع محتويات حزمة الملفات المعدلة إلى جذر المستودع.
3. انتظر نجاح GitHub Actions.
4. ادمج طلب السحب في `main`.
5. انتظر اكتمال نشر GitHub Pages.

لا يوجد SQL جديد، ولا تضف أسرارًا جديدة.

## ثانيًا: تحديث Edge Function من المتصفح

1. افتح في GitHub على فرع `main`:
   `supabase/functions/generate-source-questions/index.ts`
2. اضغط **Raw** وانسخ الملف كاملًا.
3. افتح Supabase ثم **Edge Functions**.
4. افتح الوظيفة الموجودة:
   `generate-source-questions`
5. افتح محرر الكود، احذف النسخة القديمة والصق الكود الجديد.
6. اضغط **Deploy function**.

## ثالثًا: اختبار القبول

1. افتح واثق ونفذ تحديثًا قويًا.
2. افتح **مرجع التقويم** وتأكد أن الوثيقة الأصلية تفتح.
3. أنشئ اختبارًا جديدًا للصف العاشر والفيزياء.
4. يجب أن تظهر المواصفة تلقائيًا:
   - 10 درجات.
   - 6 مفردات في قالب واثق المتوافق: 2 اختيار من متعدد، 3 قصيرة، 1 طويلة.
   - 4 معرفة، 4 تطبيق، 2 استدلال.
5. اختر موضوعًا موجودًا في الكتاب واضغط التالي.
6. تحقق من ظهور ثلاثة بدائل لكل مفردة مع الإجابة والدليل والصفحة.

عند ظهور خطأ في التوليد، لا تعِد فهرسة الكتاب؛ افتح سجل الوظيفة وأرسل الخطأ نفسه.
