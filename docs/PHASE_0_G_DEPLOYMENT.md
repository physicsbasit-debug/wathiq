# نشر Phase 0-G

## الترتيب

1. ارفع الحزمة إلى فرع مستقل وافتح Pull Request.
2. بعد نجاح الفحص، نفّذ `supabase/phase_0_g_pdf_extraction.sql` من SQL Editor.
3. استبدل كود `google-drive-oauth` بالكود الجديد وانشر الدالة.
4. تأكد أن Verify JWT with legacy secret ما زال OFF.
5. ادمج Pull Request وانتظر GitHub Pages.
6. اختبر مصدر PDF نصيًا صغيرًا أولًا.
7. اختبر ملفًا مصورًا للتأكد من ظهور يحتاج OCR.
