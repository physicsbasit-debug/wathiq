# Phase 0-G — معايير القبول

تُقبل المرحلة عند تحقق الآتي:

- [ ] ينفذ ملف SQL دون أخطاء.
- [ ] تُنشر Edge Function المحدّثة مع بقاء Verify JWT مغلقًا.
- [ ] ينجح GitHub Actions.
- [ ] يظهر زر استخراج وفهرسة للمصدر المرفوع فقط.
- [ ] يتقدم الاستخراج صفحة صفحة دون إعادة تحميل الصفحة.
- [ ] يبقى المصدر موجودًا بعد التحديث وتظهر بيانات الصفحات والحروف.
- [ ] تظهر معاينة نص وعناوين مرشحة لملف نصي.
- [ ] يظهر الملف المصور بحالة يحتاج OCR دون إنشاء مقاطع فارغة.
- [ ] إعادة الفهرسة تستبدل المقاطع القديمة ولا تكررها.
- [ ] الأرشفة والاستعادة لا تحذف نتيجة الفهرسة.
- [ ] لا يظهر النص الكامل للمصدر في واجهة المعلم.
