## فحص Word

تم إنشاء نموذج Word HTML متوافق وتحويله بواسطة LibreOffice إلى PDF:

- فتح الملف بنجاح.
- حجم الصفحة A4.
- اتجاه العربية صحيح.
- عنوان الاختبار والسؤال وبصمة الاعتماد ظاهرة.

كما أضيف مسار متصفح يحول الرسومات SVG إلى PNG قبل تنزيل Word. هذا المسار يعتمد Canvas في المتصفح، لذلك يكون فحصه الحي النهائي بعد نشر GitHub Pages.

- Word يصدر بصيغة `.doc` متوافقة، وليس `.docx` أصليًا.

- الاختبار الحي للنوافذ المنبثقة والتنزيل يحتاج المتصفح بعد النشر.
