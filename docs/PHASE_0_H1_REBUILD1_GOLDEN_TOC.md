# Phase 0-H1 Rebuild 1 — Golden TOC

## سبب إعادة البناء

الإصلاحات السابقة قبلت نتائج ناقصة أو استخدمت عناوين صفحات المحتوى بدل الفهرس. أُعيد بناء القرار بحيث يكون الفشل الآمن هو النتيجة الافتراضية: إذا لم يكتمل الفهرس، لا تُنشأ مسودة.

## المرجع الذهبي

- 11 وحدة.
- 29 درسًا.
- الوحدة الأولى: الشحنة الكهربائية، صفحة 15.
- الوحدة الحادية عشرة: احتياطات السلامة، صفحة 109.
- لا أرقام صفحات داخل العناوين.
- لا فجوات في تسلسل الوحدات.

## قواعد القبول

- كل وحدة مذكورة في صفحة الفهرس يجب أن تحتوي درسًا واحدًا على الأقل.
- الوحدات مرتبة رقميًا ومتتابعة.
- رمز الدرس يحدد الوحدة الأب بصرف النظر عن ترتيب OCR.
- النص القصير العربي الصحيح مقبول إذا كان درسًا مرقمًا صراحة.
- خطة مسح عناوين الصفحات الداخلية معطلة افتراضيًا.
