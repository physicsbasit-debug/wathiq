# Phase 2-A Fix 5 — Draft Checkpoints & Calculation Input Integrity

## المشكلة الأولى: المسودات

كان التخزين المحلي يحتفظ بمسودة واحدة فقط، وكان إنشاء اختبار جديد قادرًا على استبدالها. كما كان الحفظ المؤجل غير كافٍ قبل طلبات Gemini الطويلة أو عند مغادرة الصفحة سريعًا.

## العلاج

- مخزن محلي متعدد المسودات حتى 12 مسودة.
- حفظ فوري قبل طلب V2 وبعد النجاح أو الفشل.
- حفظ عند إخفاء الصفحة أو مغادرتها.
- تعيين مسودة نشطة واستئناف أي مسودة من «اختباراتي».
- حذف مسودة واحدة دون حذف البقية.
- ترحيل المسودة القديمة تلقائيًا.
- عند امتلاء سعة المتصفح تزال أقدم المسودات غير النشطة تدريجيًا بدل إسقاط حفظ المسودة الحالية.

## المشكلة الثانية: السؤال الحسابي

كان المدقق يفحص القيم والوحدات داخل `fixedVisual` وحده، مع أن السؤال الصحيح قد يضع جزءًا من المعطيات في النص وجزءًا في الرسم أو الجدول.

## العلاج

يفحص الخادم الآن المادة المشتركة من:

- نص السؤال.
- المثير النصي.
- عنوان الرسم ووصفه.
- القيم والمتجهات.
- أعمدة الجدول وخلاياه الظاهرة.

وتبقى قواعد خاصة لمسائل العزم والضغط والجداول الحسابية لمنع قبول سؤال ناقص.

## حدود المرحلة

الحفظ محلي في المتصفح والجهاز نفسه. المزامنة السحابية للمسودات مرحلة مستقلة لاحقة.
