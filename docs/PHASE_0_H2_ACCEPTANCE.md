# معايير قبول Phase 0-H2

- يفتح زر منشئ الفهرس مسودة حتى عند نقص رموز OCR.
- تعرض المسودة النوع والرمز والعنوان والصفحة ومصدر السطر.
- يمكن تعديل الصفوف وإضافتها وحذفها وترتيبها.
- يعرض نص OCR المرجعي.
- لا تستدعي عملية فتح المسودة `replaceSourceStructure`.
- لا يحذف الهيكل السابق عند فتح مسودة جديدة أو إلغائها.
- يمكن حفظ هيكل صالح كمسودة.
- لا يمكن اعتماد وحدة بلا دروس أو هيكل بصفحات متراجعة.
- تبقى الواجهة RTL ومتجاوبة.
- ينجح البناء وجميع الاختبارات.
