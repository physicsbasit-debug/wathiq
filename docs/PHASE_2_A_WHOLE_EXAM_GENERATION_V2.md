# Phase 2-A — Whole Exam Generation V2

## الهدف
إضافة محرك جديد يعمل بجانب المحرك السابق، ويصمم الاختبار القصير كاملًا في طلب واحد بدل توليد المفردات على دفعات منفصلة.

## النطاق المنفذ
- إضافة وضعين للتوليد داخل إعداد الاختبار:
  - `whole_exam_v2`: تصميم الاختبار كاملًا، وهو الافتراضي للاختبارات القصيرة حتى 12 مفردة.
  - `legacy_items`: المحرك السابق بوصفه خطة رجوع.
- إنشاء بطاقات درس تشغيلية تلقائيًا من أهداف الخطة ومقاطع الكتاب أو دليل المعلم.
- إنشاء مخطط اختبار شامل يحفظ الهدف والمهارة والسياق والمثير والرسم والدرجة لكل مفردة.
- إرسال الخطة كاملة إلى Supabase Edge Function في طلب `generate_exam_v2`.
- إعادة سؤال نهائي واحد عالي الجودة لكل مفردة بدل ثلاثة بدائل أولية.
- اختيار الأسئلة الناتجة تلقائيًا مع بقاء إمكان تجديد مفردة منفردة.
- مراجعة شاملة تمنع:
  - تكرار سؤالين أو بنية نصية شبه متطابقة.
  - إعادة مجموعة البيانات العددية نفسها في أكثر من سؤال.
  - الإفراط في أسئلة الاستدعاء المباشر.
  - تكرار بنية الرسم نفسها بصورة مفرطة.
- دعم تمرير مراجع الاختبارات العالمية عندما تكون موجودة ضمن مراجع المسودة، مع إبقاء بطاقة الدرس وحدود المنهج حاكمة.

## الحماية
- لم يُحذف المحرك السابق.
- الاختبارات النهائية التي تزيد على 12 مفردة تستخدم المحرك السابق في هذه المرحلة.
- لم يتغير SQL أو الفهرسة أو Word/PDF أو تخزين الصور.
- المسودات القديمة تُستنتج لها طريقة التوليد بأمان من إصدارها السابق.

## خارج نطاق هذه المرحلة
- استخراج بطاقات الدروس الكاملة من دليل المعلم وكتاب الطالب في شاشة اعتماد مستقلة.
- مزامنة بنك الأسئلة العالمية من Google Drive بصورة آلية.
- تشغيل V2 على الاختبارات النهائية الكبيرة.
- اختبار حي مع Gemini/Supabase؛ يلزم بعد إعادة نشر Edge Function.
