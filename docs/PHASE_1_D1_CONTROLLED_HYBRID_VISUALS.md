# Phase 1-D1 — Controlled Hybrid Scientific Visuals

## الهدف

رفع جودة المرئيات في واثق دون التضحية بالدقة العلمية أو استقرار الاختبارات. النظام الجديد لا يستبدل محرك SVG، بل يجعله طبقة الأمان الأساسية ويضيف صورًا تعليمية ثنائية الأبعاد في نطاق ضيق ومدقق.

## القرار المعماري

```text
ما يؤثر في صحة الحل = رسم حتمي
ما يثري المشهد دون حمل بيانات الحل = صورة 2D قابلة للتوليد
النصوص والقيم والأسهم = تحت سيطرة واثق
الفشل في أي طبقة = رجوع فوري إلى SVG
```

## نطاق الصور المولدة

المرحلة الأولى تسمح فقط بمشاهد محدودة يمكن فحصها بوضوح، منها:

- الكهرباء الساكنة: مشهد انتقال الشحنة بالدلك، بشرط ألا يكون السؤال حسابيًا أو سؤال إكمال/رسم.
- الضغط في السوائل: جسم مغمور في سائل لأدوار القراءة أو التفسير أو التقييم.

وتبقى الأنواع التالية حتمية:

- مخططات القوى.
- الدوائر الكهربائية.
- الأشعة والعدسات.
- أجهزة القياس وتدريجاتها.
- الجداول والرسوم البيانية.
- مخططات العمليات.
- أي رسم يحمل قيمًا أو وحدات أو اتجاهات لازمة للحل.

## خط أنابيب الصورة

1. يحدد واثق أهلية الرسم من نوعه ودوره وقالب الرسم.
2. يرسل وصفًا مقيدًا لإنشاء صورة تعليمية ثنائية الأبعاد بنسبة `4:3`.
3. يمنع النصوص والعناوين والقيم والوحدات والأسهم والرموز العلمية داخل الصورة.
4. يمرر الصورة إلى فحص بصري علمي منظم.
5. لا يقبلها إلا إذا تطابقت مع العناصر المطلوبة ولم تضف عناصر مضللة.
6. يخزن الصورة المقبولة في Supabase Storage.
7. يحفظ في المسودة رابط الصورة ومسارها وبصمتها ونتيجة الفحص فقط.
8. يبقى الرسم الحتمي داخل الصفحة كخطة رجوع.

## الحماية من التخريب

- لا تغيير في بنية الأسئلة أو درجاتها.
- لا حذف لمسودات الإصدارات السابقة.
- لا تحويل للرسوم الحساسة إلى صور حرة.
- لا تخزين Base64 داخل Local Storage أو المسودة.
- لا توازٍ في توليد الصور؛ التنفيذ متسلسل وبحد أقصى ثلاثة مشاهد تلقائيًا.
- عند تبديل المسودة أثناء طلب الصورة، تُهمل النتيجة القديمة ولا تُكتب في المسودة الجديدة.
- عند تعطيل الخيار، تختفي أوامر التوليد وتستمر الرسوم الحالية والحتمية.
- عند تعطل API أو الفحص أو التخزين أو التصدير، يستمر الاختبار بالرسم الحتمي.

## تحسينات القابلية للحل والطباعة

- يضيف محرك القوى القيم بوحدة نيوتن عندما يكون دور المرئي حسابيًا.
- يعرض مخطط الضغط القوة والمساحة بوحداتهما في الأسئلة الحسابية.
- لا يعرض في ورقة الطالب عنوانًا تقنيًا مركبًا لا يخدم السؤال.
- تخفض ارتفاعات الرسوم في الطباعة وWord لتقليل الصفحات شبه الفارغة.
- يخفي وصف الرسم الطويل في نسخة الطالب ويبقيه في المراجعة.

## التخزين

اسم الحاوية:

```text
wathiq-question-visuals
```

تنشأ تلقائيًا عند أول صورة ناجحة. الصور عامة لأنها جزء من ورقة اختبار قابلة للطباعة، لذلك يجب ألا تتضمن بيانات شخصية أو صور أشخاص حقيقيين.

## الإعدادات

لا يلزم سر جديد. يستخدم الطلب مفتاح Gemini الموجود في الوظيفة. يوجد متغير اختياري:

```text
GEMINI_IMAGE_MODEL
```

والقيمة الافتراضية في الكود:

```text
gemini-3.1-flash-image
```

## حدود المرحلة

- لا توليد لصور مجهرية أو تشريحية معقدة في هذه المرحلة.
- لا اقتصاص تلقائي من صور الكتاب.
- لا محرر طبقات رسومية يدوي.
- لا حذف فوري للصورة القديمة عند اختيار العودة إلى الرسم الحتمي؛ تُزال الصورة السابقة عند إعادة التوليد الناجحة بقدر الإمكان.
- الاتصال الحي بالخدمات الخارجية يحتاج اختبار قبول بعد النشر.
