## الخطوات

1. أنشئ الفرع من `main`.
2. ارفع محتويات حزمة Changed Files Only إلى جذر المستودع مع الاستبدال.
3. احفظ التغييرات بالرسالة المحددة.
4. افتح Pull Request إلى `main`.
5. انتظر GitHub Actions الخضراء قبل الدمج.

## بعد الدمج

لا يوجد SQL ولا Edge Function ولا تعديل `pages.yml`.
بعد اكتمال GitHub Pages حدّث واثق تحديثًا قويًا، ثم جرّب موضوعًا موجودًا فعلًا في كتاب مفهرس.
