# Phase 0-G Fix 1 — إصلاح الحفظ المركزي بعد التحديث

## المشكلة

بعد تنفيذ SQL الخاص بـPhase 0-G، أصبح الحقل `extraction_status` في جدول `source_registry` إلزاميًا وله قيمة افتراضية `لم يبدأ`.
المصادر المحلية القديمة لا تحتوي هذا الحقل، وكان التطبيق يرسل له قيمة `null` صراحةً عند المزامنة بعد تحديث الصفحة، فتُرفض عملية الحفظ المركزي وتبقى النسخة المحلية فقط.

## الإصلاح

- إرسال القيمة `لم يبدأ` للمصادر القديمة التي لا تملك حالة استخراج بعد.
- إضافة اختبار قبول يمنع رجوع إرسال `null` لهذا الحقل.
- لا تعديل على SQL أو Edge Function أو Google Drive.
