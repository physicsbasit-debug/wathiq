# Phase 0-H1 Fix 2 — تنظيف المسودة القديمة المشوهة

## المشكلة

بقيت المسودة الرديئة المخزنة في Supabase ظاهرة بعد نشر Fix 1، لأن Fix 1 شدد الاستخراج الجديد لكنه لم يرحّل البيانات القديمة تلقائيًا.

## الحل

- فحص المسودة المحفوظة عند تحميل تفاصيل المصدر.
- عزلها فقط إذا كانت غير معتمدة، وغير يدوية، ومن إصدار قديم، وتحتوي نسبة واضحة من المعادلات أو الوحدات الوهمية.
- حذفها من جدول `source_structure_nodes`.
- عرض رسالة واضحة ثم السماح بالاستخراج الموثوق أو إدخال صفحات الفهرس يدويًا.

## خارج النطاق

- لا تغيير على استخراج OCR أو المقاطع النصية.
- لا SQL جديد.
- لا Edge Function جديدة.
- لا تعديل على GitHub Pages.
