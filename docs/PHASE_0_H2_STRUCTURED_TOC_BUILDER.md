# Phase 0-H2 — Structured TOC Builder

## المشكلة المغلقة

كان مسار H1 يرفض النتيجة كاملة إذا أخطأ OCR في عدد محدود من رموز الدروس. هذا جعل المستخدم يعيد OCR أو يطلب ترقيعات متتالية رغم أن النص والإحداثيات كانا متاحين بالفعل.

## القرار المعماري

OCR مسؤول عن قراءة الكلمات ومواقعها فقط. الواجهة تبني مسودة قابلة للمراجعة، ولا تتحول إلى هيكل محفوظ إلا بقرار صريح من مالك المنصة.

## الملفات الرئيسية

- `src/toc-draft-builder.ts`: بناء صفوف المسودة وتحويلها إلى عقد الهيكل.
- `src/app.ts`: جدول المراجعة، الإجراءات، وعدم الحفظ التلقائي.
- `src/source-structure.ts`: فصل تحقق المسودة عن تحقق الاعتماد.
- `src/styles.css`: تخطيط الجدول على الحاسوب والهاتف.

## خارج النطاق

- لا تعديل على Google Vision أو Edge Function.
- لا SQL جديد.
- لا تعديل على GitHub Pages workflow.
- لا حذف لملفات H1 القديمة في هذه الدفعة.
