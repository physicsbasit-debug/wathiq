# Phase 0-D — سجل المصادر المنظم

## الهدف

تثبيت سجل مصادر واضح وقابل للنقل قبل ربط Google Drive أو قاعدة بيانات إنتاجية.

## داخل النطاق

- رقم فهرسة تلقائي لكل مصدر.
- تحديد جهة المصدر تلقائيًا: منهج عُماني، كامبريدج، أو مصدر عالمي.
- بصمة داخلية لكشف المصدر المكرر.
- منع تسجيل المصدر نفسه مرتين.
- عرض تفاصيل المصدر في بطاقة واضحة.
- تصدير سجل المصادر إلى JSON.
- استيراد نسخة واثق صحيحة ودمجها دون تكرار.
- ترقية بيانات Phase 0-C المحلية تلقائيًا إلى السجل الجديد.

## خارج النطاق

- رفع ملف PDF الفعلي إلى Google Drive.
- تنزيل المحتوى من الروابط.
- استخراج النصوص أو الصور.
- الفهرسة العلمية الحقيقية.
- قاعدة بيانات أو حسابات مستخدمين إنتاجية.

## معايير القبول

- [ ] لا يمكن إضافة المصدر نفسه مرتين.
- [ ] يظهر رقم فهرسة لكل مصدر.
- [ ] تعمل نافذة التفاصيل على الحاسوب والهاتف.
- [ ] يُصدّر ملف JSON صالح.
- [ ] يستورد ملف JSON صادرًا من واثق.
- [ ] يتجاوز الاستيراد السجلات المكررة.
- [ ] يرفض الملف التالف أو غير المعتمد.
- [ ] تنتقل بيانات Phase 0-C المحلية دون فقد.
- [ ] ينجح GitHub Actions.
