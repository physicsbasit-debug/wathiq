# Phase 1-C2 Fix 4 — ربط صفحات شجرة الكتاب بصفحات PDF

## المشكلة
شجرة كتاب الفيزياء كانت تخزن أرقام الصفحات المطبوعة، بينما المقاطع المفهرسة تستخدم رقم صفحة ملف PDF الفعلي. يتقدم ترقيم PDF بثلاث صفحات بسبب الغلاف والصفحات التمهيدية، لذلك لم تتقاطع نطاقات الدروس مع المقاطع الصحيحة.

## الإصلاح
- إضافة إزاحة PDF موثقة مقدارها `+3` لكتاب الفيزياء الحالي.
- تحويل نطاق كل وحدة ودرس إلى صفحات PDF عند بناء الشجرة.
- البحث أولًا داخل النطاق الدقيق، ثم ضمن هامش آمن ±3 صفحات لمعالجة حدود المقاطع، ثم بحث صارم بعنوان الدرس داخل المصدر نفسه فقط.
- رفع إصدار الاسترجاع إلى `strict-lesson-scope-3-pdf-pages` لإبطال المراجع القديمة الخاطئة.
- لا OCR ولا Gemini ولا إعادة فهرسة ولا تغيير في Supabase.
