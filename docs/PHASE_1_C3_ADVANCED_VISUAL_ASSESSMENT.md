# Phase 1-C3 — Advanced Visual Assessment Engine

## الهدف

توسيع محرك المرئيات في واثق بحيث تصبح الرسوم والجداول والأشكال جزءًا من القياس، لا عنصرًا زخرفيًا. يعتمد التنفيذ الملخص التحليلي لنماذج كامبريدج، مع بقاء وثيقة التقويم العُمانية حاكمة للدرجات وأنواع المفردات وأهداف التقويم.

## مبدأ التصميم

كل مفردة بصرية تحمل:

- `visualTarget`: عائلة المرئي.
- `role`: العمل العقلي الذي يؤديه الطالب باستخدام المرئي.
- `visualSpec`: مواصفة منظمة وآمنة.
- `visualId`: معرف ثابت يمنع الخلط والتكرار.

### أدوار المرئي

- `read`: قراءة قيمة أو تسمية.
- `calculate`: استخدام بيانات المرئي في حساب.
- `interpret`: تفسير اتجاه أو علاقة.
- `compare`: مقارنة حالتين أو سلسلتين.
- `complete`: إكمال خلية أو مرحلة ناقصة.
- `draw`: إكمال مسار أو رسم مطلوب.
- `evaluate`: تقييم طريقة أو نتيجة تجريبية.

## الأنواع الجديدة

### 1. جداول البيانات العلمية `data_table`

- عناوين أعمدة ووحدات واضحة.
- صفوف وبيانات منظمة.
- إمكانية إخفاء خلية محددة في ورقة الطالب.
- قوالب أولية لبيانات الحرارة، والكهرباء، والضغط، والقياسات العامة.

### 2. تدريجات الأجهزة `instrument_scale`

- ميزان حرارة.
- سحاحة.
- مخبار مدرج.
- أميتر أو فولتميتر.
- مواصفة تحدد الحدين، وأصغر تدريج، والقراءة، والوحدة.

### 3. مخططات الأشعة `ray_diagram`

- الانعكاس.
- الانكسار.
- العدسة المحدبة.
- المنشور.
- أسهم اتجاه وعناصر بصرية معيارية.

### 4. مخططات القوى `force_diagram`

- مخطط جسم حر.
- قوى متزنة وغير متزنة.
- عزوم حول نقطة ارتكاز.
- متجهات تحمل الاسم والاتجاه والمقدار النسبي.

### 5. مخططات العمليات `flow_diagram`

- تسلسل خطي.
- دورة.
- تحولات حالة المادة.
- تحولات الطاقة.

### 6. الرسوم متعددة السلاسل

وسع `line_graph` ليعرض سلسلتين أو أكثر مع مفتاح واضح وأنماط خطوط قابلة للتمييز في الأبيض والأسود.

## ملكية الخادم للمرئيات

لا يطلب واثق من Gemini إنشاء SVG أو صورة. يقوم الخادم ببناء `fixedVisual` حتميًا من موضوع الدرس ونمط المفردة، ثم يطلب من Gemini صياغة سؤال يعتمد على ذلك المرئي. بعد نجاح السؤال، تُضاف المواصفة البصرية إلى المفردة.

هذا يمنع:

- الرسومات العلمية الخاطئة أو الحرة.
- فقد السؤال بسبب JSON بصري ناقص.
- تكلفة طلبات توليد صور إضافية.
- إدخال HTML أو SVG خام من النموذج.

## اختيار النوع

تستنتج الواجهة نوع المرئي من نص الدرس والمقطع المصدر، مع ضوابط تمنع الخلط. مثال مهم: كلمة «الإشعاع» لا تُعامل كـ«شعاع ضوئي»، لذلك لا يتحول درس النشاط الإشعاعي إلى مخطط بصريات.

## التحقق

يفحص `parseQuestionVisualSpec` و`validateQuestionVisualSpec`:

- النوع والنسخة.
- المحاور والوحدات والنطاقات.
- تطابق السلاسل مع حدود الرسم.
- تطابق خلايا الجدول مع الصفوف والأعمدة.
- صحة الخلايا المخفية.
- اكتمال تدريج الجهاز.
- اكتمال متجهات القوة.
- وجود مكونات الدائرة الأساسية.
- سلامة النصوص من HTML وروابط أو صور خارجية.

## العرض والتصدير

تُرسم جميع الأنواع بصيغة SVG داخل:

- معاينة البدائل.
- ورقة الطالب.
- نموذج الإجابة.
- Word وPDF عبر مسار التصدير القائم.

أضيفت قواعد طباعة تحفظ التباين والخطوط والحدود في الأبيض والأسود.

## ما لم يُنفذ في C3

- اقتصاص صور أو رسوم من صفحات الكتاب.
- الصور المجهرية والتشريحية الواقعية.
- مكتبة أجهزة الكيمياء المركبة.
- طبقة `answerOverlay` رسومية مستقلة.
- رسم الطالب داخل المتصفح.

هذه ليست عيوبًا مخفية؛ هي نطاق لاحق يحتاج إدارة مصادر وصور وحقوق وطبقات إجابة مستقلة.
