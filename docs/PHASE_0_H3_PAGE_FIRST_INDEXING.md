# Phase 0-H3 — Page-First Indexing

## القرار

أُلغي تحليل فهرس الكتاب بصريًا من مسار التشغيل. المصدر يصبح جاهزًا بعد استخراج النص وحفظ المقاطع مع أرقام الصفحات.

## المسار المعتمد

1. رفع PDF.
2. استخراج النص من طبقة PDF أو OCR العربي عند الحاجة.
3. حفظ النص حسب الصفحة والمقطع.
4. استخدام المقاطع في البحث والاسترجاع وبناء الاختبارات.

## ما لم يعد مطلوبًا

- اكتشاف صفحات الفهرس.
- OCR موضعي للفهرس.
- استخراج الوحدات والدروس تلقائيًا.
- اعتماد هيكل كتاب قبل استخدام المصدر.

## التوافق

الجداول والملفات القديمة لا تُحذف، لكنها لم تعد مستدعاة من واجهة التشغيل. لا يوجد SQL أو Edge Function جديد.
