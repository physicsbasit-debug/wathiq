# Phase 1-C2 Fix 3 — شجرة الكتاب والوحدات والدروس

## المشكلة

فشل استخراج فهرس الدروس من النص المفهرس لكتاب الفيزياء الحالي، فأصبحت شاشة اختيار الدروس فارغة رغم نجاح فهرسة صفحات الكتاب ومقاطعه.

## القرار

فصل جاهزية المحتوى العلمي عن جاهزية شجرة التنقل. يظل النص المفهرس مصدر الأسئلة، بينما تستخدم شجرة موثقة لاختيار الوحدة والدرس ونطاق الصفحات.

## التنفيذ

- إضافة سجل بنيوي محلي للكتب المعروفة في `src/book-content-tree.ts`.
- دعم كتاب الطالب للفيزياء للصف العاشر، الفصل الأول:
  - 11 وحدة.
  - 29 درسًا.
  - نطاق صفحات لكل وحدة ودرس.
- مطابقة آمنة للمصدر عبر:
  - الصف.
  - المادة.
  - نوع المصدر.
  - الفصل الدراسي.
  - رقم الفهرسة أو اسم الملف/العنوان.
  - عدد الصفحات ضمن هامش محدود.
- عرض هرمي باستخدام عناصر HTML أصلية قابلة للفتح والإغلاق:
  - الكتاب.
  - الوحدة.
  - الدروس.
- إبقاء الحد الرسمي للاختيار من درسين إلى خمسة.

## الاسترجاع

لم يعد واثق يبحث عن الدرس في جميع مقاطع المصادر المطابقة. لكل درس مختار:

1. يحدد المصدر المرتبط به.
2. يحدد بداية ونهاية صفحات الدرس.
3. يقصر المقاطع المرشحة على الصفحات المتداخلة مع هذا النطاق.
4. يرتب المقاطع داخل النطاق بالاسترجاع النصي الصارم.

تم رفع إصدار الاسترجاع إلى `strict-lesson-scope-2-tree-pages` لإلغاء المراجع القديمة وإعادة مطابقتها وفق نطاقات الصفحات.

## القيود المتعمدة

- الشجرة المنسقة المدمجة حاليًا خاصة بكتاب فيزياء الصف العاشر المرفوع.
- المصادر الأخرى تستفيد من أي هيكل معتمد محفوظ في `source_structure_nodes`.
- لا يخمن واثق وحدات أو دروس مصدر غير معروف.
- إضافة كتب أخرى لاحقًا تكون بإضافة تعريف موثق للكتاب، لا بتوليد أسماء عبر Gemini.

## أثر النشر

- واجهة GitHub Pages فقط.
- لا تعديل على Edge Functions.
- لا SQL أو أسرار أو OCR أو إعادة فهرسة.
