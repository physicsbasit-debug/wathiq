# Phase 2-A Fix 3 — Visual Reference Normalization

## المشكلة

كان محرك تصميم الاختبار الكامل V2 يرفض سؤالًا بصريًا صالحًا إذا لم يذكر Gemini داخل نص السؤال عبارة صريحة مثل «الشكل المرفق» أو «الجدول المرفق»، حتى عندما كان `fixedVisual` موجودًا وجاهزًا داخل المفردة.

## الحل

أصبحت إحالة الرسم ملكًا للخادم داخل ملف Edge Function نفسه، وليست شرطًا شكليًا يترك للنموذج:

- إذا ذكر السؤال أو المثير الرسم مسبقًا، لا يغير واثق النص.
- إذا غابت الإحالة، يضيف واثق تلقائيًا عبارة مناسبة لنوع الرسم:
  - مخطط القوى.
  - مخطط الدائرة.
  - الرسم البياني.
  - الجدول.
  - تدريج الجهاز.
  - مخطط الأشعة.
  - المشهد أو الشكل العام.
- يجري التطبيع قبل فحص كفاية السياق والدليل العلمي.
- لا تتكرر العبارة إذا كانت موجودة مسبقًا.
- لا تتغير الأسئلة النصية التي لا تملك رسمًا.

## أمثلة

```text
احسب محصلة القوتين.
```

تتحول إلى:

```text
بالاستعانة بمخطط القوى المرفق، احسب محصلة القوتين.
```

أما:

```text
يوضح الشكل المرفق جسمًا متزنًا. فسّر ذلك.
```

فتبقى دون تغيير.

## خارج النطاق

- لا تغيير في الإصدار `0.0.50`.
- لا تغيير في عقد `source-grounded-policy-ai-17-whole-exam-v2`.
- لا SQL.
- لا إعادة فهرسة.
- لا تغيير في Word/PDF أو الصور أو Gemini model.
