# نشر Phase 0-H1

## الترتيب

1. ارفع حزمة Changed Files Only إلى فرع `feat/phase-0-h1-source-structure`.
2. افتح Pull Request وانتظر نجاح GitHub Actions.
3. قبل الدمج، شغّل ملف `supabase/phase_0_h1_source_structure.sql` من Supabase SQL Editor.
4. بعد ظهور `Success. No rows returned` ادمج الطلب.
5. انتظر نجاح نشر GitHub Pages.
6. افتح كتاب الفيزياء المفهرس، ثم تفاصيل المصدر.
7. اضغط «استخراج هيكل الكتاب».
8. راجع الوحدات والدروس والصفحات، واحفظ المسودة ثم اعتمد الهيكل.

## لا يلزم

- لا تعديل على Edge Function.
- لا أسرار Supabase جديدة.
- لا متغيرات GitHub جديدة.
- لا تعديل على `.github/workflows/pages.yml`.
