# Phase 0-G Fix 2B — OCR عربي فعلي

## الهدف

تحويل المصادر التي فشلت طبقة نصها أو كانت صفحاتها مصورة إلى نص عربي قابل للفهرسة، مع منع ضياع التقدم عند انقطاع الاتصال.

## المسار

1. يحمّل واثق ملف PDF من Google Drive عبر الرابط الآمن الحالي.
2. يرسم كل صفحة محليًا كصورة JPEG مضبوطة الحجم.
3. يرسل الصفحة فقط إلى Edge Function المصادق عليها.
4. تستدعي الدالة Google Cloud Vision باستخدام `DOCUMENT_TEXT_DETECTION` مع العربية والإنجليزية.
5. تحفظ نتيجة كل صفحة فورًا في `source_ocr_pages`.
6. عند الانقطاع، يقرأ واثق الصفحات المكتملة ويستأنف الناقص فقط.
7. بعد اكتمال الصفحات تمر النتيجة عبر بوابة الجودة العربية الحالية.
8. لا تُنشأ `source_chunks` إلا إذا نجح النص الناتج.

## الحماية

- مفتاح Vision يبقى داخل Supabase Edge Function Secrets.
- لا يظهر المفتاح في GitHub Pages أو المتصفح.
- كل صفحة OCR مرتبطة بـ`owner_id` و`source_id` ومحكومة بـRLS.
- الحد الأقصى للعملية الواحدة 300 صفحة.
- صورة الصفحة لا تتجاوز 10 ميجابايت.

## الحالات

- `يحتاج OCR`: لم يبدأ OCR أو طبقة النص الأصلية مرفوضة.
- `جارٍ الاستخراج`: توجد عملية OCR قابلة للاستكمال.
- `مكتمل`: OCR اجتاز الجودة وحُفظت المقاطع.
- `فشل`: OCR اكتمل لكن النص لم يجتز الجودة أو حدث خطأ.
