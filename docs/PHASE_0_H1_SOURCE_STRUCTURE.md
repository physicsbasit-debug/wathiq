# Phase 0-H1 — استخراج هيكل الكتاب من الفهرس

## الهدف

تحويل النص المفهرس للمصدر إلى شجرة منظمة من الوحدات والدروس والموضوعات والأنشطة والمراجعات والأسئلة، مع إبقاء كل عنصر مرشحًا للمراجعة قبل الاعتماد.

## طريقة الاستخراج

1. يعيد واثق تركيب نص كل صفحة من مقاطع `source_chunks`.
2. يبحث عن صفحات المحتويات التي تحتوي عدة عناوين مرتبطة بأرقام صفحات.
3. يستخرج العنوان ورقم الصفحة ويصنف نوع العنصر.
4. ينظف نقاط الفهرس وأرقام الصفحات من العنوان.
5. يزيل التكرارات ويستبعد عناوين حقوق النشر والمقدمة.
6. يربط العناصر التابعة بأقرب وحدة سابقة.
7. يحسب صفحة النهاية من بداية العنصر التالي.
8. إذا لم يجد فهرسًا واضحًا، يستخدم مسح العناوين داخل الصفحات كخطة احتياطية منخفضة الثقة.

## المراجعة

يمكن لمدير المحتوى:

- تعديل عنوان العنصر ونوعه.
- تغيير الوحدة الأب.
- تعديل صفحة البداية والنهاية.
- إعادة ترتيب العناصر.
- حذف عنصر أو إضافة وحدة وعنصر تابع.
- حفظ مسودة مركزية.
- اعتماد الهيكل بعد اجتياز التحقق.

## قاعدة البيانات

يضيف ملف SQL جدول `source_structure_nodes` مع RLS، ويربط كل عنصر بالمصدر ومالك المنصة.

## خارج النطاق

نواتج التعلم والأهداف التعليمية مؤجلة إلى Phase 0-H2.
