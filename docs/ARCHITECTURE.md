# معمارية واثق 0.2.0

## المبدأ

واثق **Cambridge-first**: اسم الموضوع والبرنامج والمرحلة يكفون لبدء التأليف. المصادر المرفوعة تعزيز اختياري فقط.

```text
Cambridge identity
  → assessment plan
  → curriculum context
  → free AI author
  → independent science reviewer
  → deterministic proof where possible
  → visual pipeline
  → global review
  → export
```

## 1. هوية Cambridge

المسارات الحية ثلاثة فقط:

- `primary`: Cambridge Primary Science 0097، Stages 1-6.
- `lower_secondary`: Cambridge Lower Secondary Science 0893، Stages 7-9.
- `igcse`: مواد علوم IGCSE المدعومة ورمز syllabus لكل مادة.

لا توجد مواد غير العلوم في هذا الإصدار.

## 2. سياق التأليف

### Global curriculum mode

إذا لم يرفع المستخدم مصدرًا، ينشئ واثق سياق Cambridge من:

- البرنامج.
- Stage أو IGCSE.
- رمز syllabus.
- المادة.
- اسم الموضوع.
- نوع السؤال والدرجة.
- سياق الاختبار المكتمل لتقليل التكرار.

لا يدعي واثق امتلاك صياغة رسمية حرفية لهدف تعلم لم تُزوَّد له؛ المؤلف والمراجع يستخدمان المعرفة الراسخة بمنهج Cambridge ضمن الموضوع والمرحلة.

### Uploaded source mode

إذا رفع المستخدم PDF، يصبح المصدر تخصيصًا إضافيًا. الاسترجاع النصي يجلب سياقًا مساعدًا فقط، ولا يملك صلاحية رفض مفردة سليمة لمجرد اختلاف الكلمات.

## 3. المؤلف والمراجع

### AI Author

القيود الصلبة الوحيدة التي تحكم المنتج هي:

- برنامج Cambridge/المادة/المرحلة/الموضوع.
- نوع السؤال.
- الدرجة.

مستوى التفكير والتحدي **توجيه تقويمي** لا قالب صياغة. المؤلف يختار أفضل سياق ومثير وبنية ومرئي إذا كان مفيدًا.

### AI Reviewer

استدعاء مستقل يراجع:

- الصحة العلمية.
- ملاءمة المحتوى للبرنامج والمرحلة والموضوع.
- جودة القياس والمشتتات.
- قابلية الحل.
- الأرقام والوحدات والعلاقات.
- الإجابة ونموذج التصحيح.
- جودة اللغة.
- ضرورة المرئي ودقته.

للمراجع صلاحية إعادة كتابة المفردة قبل اعتمادها.

## 4. التحقق الحتمي

الحتميات لا تحكم الدلالة التي لا تستطيع إثباتها. تستخدم فقط في أمور مثل:

- اتساق مجموع الدرجات.
- عدد بدائل MCQ وتفرّدها.
- عدد نقاط نموذج التصحيح.
- القيم والبيانات التي يملكها واثق.
- سلامة العقود والبصمات وملكية المستخدم ومنع النتائج القديمة.

## 5. المرئيات

مساران فقط:

- **Structured exact**: جداول، رسوم بيانية رقمية، تدريجات وبيانات دقيقة يرسمها واثق حتميًا.
- **Scientific 2D illustration**: مرئي توضيحي كامل يولده نموذج الصور ثم يراجعه مراجع علمي بصري مستقل.

لا يوجد line-art fallback للمرئيات التوضيحية.

## 6. المصادر الاختيارية

PDF يُقرأ مباشرة من الجهاز. إذا كانت طبقة النص غير صالحة يستخدم `source-ocr`. لا يوجد اعتماد على خدمة تخزين خارجية لإدخال المصدر.

## 7. الاستمرارية

كل مفردة مهمة مستقلة محفوظة في Supabase. نجاح مفردة لا ينتظر بقية الاختبار، ويمكن تحديث الصفحة واستكمال المتبقي دون إعادة العمل الناجح.
