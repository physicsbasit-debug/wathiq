# Phase 0-C — إدارة المصادر محليًا

## الهدف

إثبات أن مالك المنصة يستطيع إضافة مصدر PDF أو رابط عالمي، وتصنيفه، ومعاينة مساره المقترح في Google Drive، ثم متابعته وأرشفته دون حذف، قبل تنفيذ أي ربط خارجي حقيقي.

## النطاق

- نموذج واحد واضح لإضافة ملف PDF.
- نموذج واحد واضح لإضافة رابط عالمي.
- الصف والمادة ونوع المصدر والإصدار.
- معاينة مسار Google Drive تلقائيًا.
- حفظ المصادر محليًا في المتصفح.
- حالات: جاهز للفهرسة، مفهرس، يحتاج مراجعة، مؤرشف.
- بحث وترشيح.
- أرشفة واستعادة دون حذف.
- محاكاة انتقال المصدر إلى حالة مفهرس.

## خارج النطاق

- رفع الملف فعليًا إلى Google Drive.
- قراءة PDF أو OCR.
- جلب صفحات المواقع.
- استخراج الوحدات والدروس ونواتج التعلم.
- قاعدة بيانات أو تسجيل دخول حقيقي.

## معايير القبول

- [x] إضافة PDF لا تتطلب أكثر من نموذج واحد.
- [x] إضافة رابط تتطلب تأكيد مراجعة حقوق الاستخدام.
- [x] المسار المقترح يتغير حسب النوع والصف والمادة.
- [x] المصادر تبقى بعد تحديث الصفحة عبر التخزين المحلي.
- [x] الأرشفة لا تحذف المصدر.
- [x] يمكن البحث والترشيح حسب الحالة.
- [x] الواجهة متجاوبة وRTL.
- [x] اختبارات وظائف المصادر تنجح.
- [x] لا توجد ادعاءات بتكامل خارجي غير منفذ.
