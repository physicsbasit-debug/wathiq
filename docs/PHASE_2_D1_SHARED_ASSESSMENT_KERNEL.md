# Phase 2-D1 — نواة عقود التوليد المشتركة

## الهدف

إنشاء نواة مستقلة قبل بناء الجداول أو العامل الخادمي. النواة لا تستدعي Gemini ولا Supabase ولا الواجهة، ولا تعتمد على المحرك السابق.

## الوحدات الجديدة

```text
src/assessment-engine/
  contracts.ts
  hashing.ts
  errors.ts
  invariants.ts
  blueprint.ts
  normalization.ts
  global-review.ts
  index.ts
```

## القرارات المعتمدة

### 1. ملكية الخادم للعقد

النموذج يعيد فقط:

- المثير.
- نص السؤال.
- البدائل.
- الإجابة.
- التفسير.
- نقاط التصحيح.
- وسم المراجعة.

ولا يعيد معرف الخطة أو الدليل أو المصدر أو الرسم أو النموذج العلمي أو الدرجات.

### 2. مصدر صريح لكل مفردة

كل مفردة تحمل `AssessmentSourceSnapshot` يتضمن:

- `sourceId`.
- `sourceReferenceId`.
- `chunkIndex` كعدد صريح.
- نطاق الصفحات.
- بصمة المحتوى.
- إصدار الاستخراج.

لا تُستخرج هوية المقطع من نص معرف مركب.

### 3. ثلاثة أرقام إصدار فقط

```text
engineSchemaVersion = 1
contractVersion = 1
blueprintVersion = 1
```

أي تغيير لاحق يحتاج ترحيلًا واضحًا بدل سلسلة أسماء عقود متراكمة.

### 4. بصمات حتمية

- `planHash`: الخطة دون محتوى المصدر.
- `sourceSnapshotHash`: لقطات المصادر.
- `contractHash`: عقد المفردة كاملًا.
- ترتيب مفاتيح JSON لا يغير البصمة.

### 5. آلة حالات صريحة

المسار المسموح:

```text
queued
→ grounding
→ generating
→ normalizing
→ validating
→ ready
```

مع حالات منفصلة لإعادة المحاولة والإلغاء والإزاحة. الانتقال غير القانوني يرفض فورًا.

### 6. التطبيع المحلي لا يخترع محتوى

التطبيع ينظف النص والبدائل ويمنع الحقول المحظورة، لكنه لا يؤلف نقاط تصحيح بديلة. إذا لم يساو عدد نقاط التصحيح درجة السؤال، تُصنف المشكلة على أنها خلل محتوى يستدعي محاولة مفردة واحدة فقط في العامل المستقبلي.

### 7. المراجعة العامة تعيد تعارضات لا أسئلة

`reviewCompletedAssessment()` تكشف:

- تشابه الصياغة.
- تكرار مجموعات الأرقام.
- زيادة الاستدعاء المباشر.

وتعيد معرفات المفردات المتعارضة. قرار إعادة مفردة بعينها سيكون من مسؤولية المنسق، لا من مسؤولية المراجعة.

## ما لم يُربط بعد

- لا توجد جداول SQL جديدة في هذه المرحلة.
- لا توجد Edge Function جديدة.
- لا يوجد تغيير في واجهة المستخدم.
- لا توجد كتابة على المسودة.
- لا يوجد استدعاء للمحرك السابق من النواة.

هذا الفصل متعمد: النواة يجب أن تثبت بالعزل قبل أن تصبح جزءًا من مسار إنتاجي.
