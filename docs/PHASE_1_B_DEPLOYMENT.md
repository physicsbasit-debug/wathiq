# Phase 1-B3 — نشر توليد الأسئلة متعدد الدروس عبر Gemini

هذه هي تعليمات النشر الحالية لواثق. لا يستخدم هذا المسار OpenAI، ولا يحتاج Codespaces أو طرفية أو SQL.

## الأسرار المطلوبة في Supabase

تأكد من وجود الأسرار التالية داخل المشروع:

- `GEMINI_API_KEY`
- `WATHIQ_APP_URL`
- `GEMINI_MODEL` اختياري، والقيمة الافتراضية `gemini-2.5-flash`.

لا تضع أي مفتاح داخل GitHub أو `runtime-config.js` أو سجل الوظيفة.

## نشر الوظيفة بالطريقة المعتمدة للمشروع

1. بعد دمج الفرع في `main`، افتح في GitHub:
   `supabase/functions/generate-source-questions/index.ts`
2. اضغط **Raw** وانسخ الملف كاملًا.
3. افتح Supabase ثم:
   **Edge Functions → generate-source-questions → محرر Supabase**.
4. احذف الكود السابق والصق الملف الجديد كاملًا.
5. اضغط **Deploy function** وانتظر نجاح النشر.

## اختبار ما بعد النشر

1. انتظر اكتمال GitHub Pages باللون الأخضر.
2. افتح واثق ونفذ تحديثًا قويًا `Ctrl + F5`.
3. أنشئ اختبارًا قصيرًا للصف العاشر.
4. أدخل من درسين إلى خمسة، مثل:
   - `1-1 الضغط`
   - `1-2 الضغط في السوائل`
   - `1-3 الضغط الجوي`
5. انتقل إلى الإعداد ثم التوليد.
6. يجب أن يظهر تقدم الدفعات، وأن تحتفظ الواجهة بالدفعات المكتملة إذا فشلت دفعة لاحقة.

لا تعِد فهرسة الكتاب إذا كانت حالته جاهزة للاستخدام.
