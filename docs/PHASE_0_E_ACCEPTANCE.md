# معايير قبول Phase 0-E

## البناء والفحوص

- [ ] ينجح GitHub Actions.
- [ ] تنجح جميع الاختبارات.
- [ ] تنجح معاينة GitHub Pages.

## الوضع المحلي

- [ ] عند غياب متغيرات Supabase يظهر بوضوح أن السجل محلي.
- [ ] تظل إضافة المصادر والأرشفة والاستيراد والتصدير عاملة محليًا.

## الوضع المركزي

- [ ] بعد ضبط المتغيرات تظهر شاشة تسجيل دخول مالك المنصة.
- [ ] يرفض الدخول بالبيانات غير الصحيحة برسالة مفهومة.
- [ ] ينجح الدخول بحساب Supabase المعتمد.
- [ ] ينتقل السجل المحلي إلى Supabase تلقائيًا دون تكرار.
- [ ] تظهر المصادر نفسها في جهاز أو متصفح آخر بعد تسجيل الدخول.
- [ ] إضافة مصدر جديد تحفظه مركزيًا ومحليًا.
- [ ] تغيير الحالة والأرشفة والاستعادة تنتقل إلى السجل المركزي.
- [ ] عند تعذر الشبكة تبقى النسخة المحلية ولا تضيع العملية بصمت.
- [ ] تسجيل الخروج يعيد الواجهة إلى حالة طلب الدخول.

## الأمن

- [ ] جدول `source_registry` مفعّل عليه RLS.
- [ ] دور `anon` لا يملك صلاحية على الجدول.
- [ ] المستخدم لا يرى إلا السجلات التي يملكها.
- [ ] لا يوجد Secret key أو Service Role داخل المستودع أو ملفات الموقع المبنية.

## خارج النطاق

- رفع ملفات PDF الفعلية.
- Google Drive.
- استخراج النصوص أو الفهرسة الحقيقية.
- حسابات المعلمين.
