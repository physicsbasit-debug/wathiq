# Phase 1-B2 — مرجع التقويم الرسمي

## الهدف

إدخال وثيقة تقويم العلوم إلى واثق كمرجع تنظيمي فعلي، لا كمجرد ملف في المكتبة، وتطبيق قالب اختبار قصير متوافق تلقائيًا قبل توليد الأسئلة.

## التنفيذ

- إضافة ملف قواعد منظم: `src/assessment-policy.ts`.
- إضافة صفحة واجهة: **مرجع تقويم العلوم**.
- تضمين الوثيقة الأصلية في `references/` ونسخها إلى إصدار GitHub Pages أثناء البناء.
- قصر صفوف مسار الاختبار الرسمي على 5-10.
- تطبيق القالب حسب الصف وإلغاء التعديل اليدوي للأعداد والدرجات الرسمية.
- بناء الخطة بدرجات فعلية لكل مفردة بدل افتراض ثابت لكل نوع.
- تمرير رقم المرجع ونوع التقويم إلى Edge Function والتحقق منهما في الخادم.
- تحديث طلب Gemini إلى المسار المستقر `/v1/interactions` مع المخرجات المنظمة.
- ترحيل المسودات القديمة تلقائيًا إلى القالب الجديد ومسح التوليد القديم غير المتوافق.

## لا يشمل

- لا SQL جديد.
- لا إعادة فهرسة.
- لا تحليل فهرس بصري.
- لا تغيير لمفتاح Gemini.
- لا إعادة تصميم واسعة للمنصة.
