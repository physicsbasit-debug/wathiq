# Phase 0-H1 Fix 1 — بوابة موثوقية هيكل الكتاب

## المشكلة

كانت خوارزمية Phase 0-H1 تقبل صفحات علمية مليئة بالمعادلات والرموز على أنها صفحات فهرس، ثم تصنف السطور الرقمية افتراضيًا كوحدات ودروس بدرجات ثقة مرتفعة.

## الإصلاح

- لا تُقبل صفحة فهرس تلقائيًا إلا عند وجود عنوان واضح مثل «المحتويات» أو «الفهرس».
- يشترط تسلسل منطقي لأرقام الصفحات، ووجود وحدة صريحة، وعدد كافٍ من العناصر التعليمية.
- أُلغي تصنيف السطر الرقمي العام كوحدة.
- تُرفض المعادلات والرموز والعناوين القصيرة الغامضة.
- عند غياب فهرس موثوق، يُستخرج فقط ما يطابق عنوان وحدة صريحًا داخل الكتاب.
- أضيف إدخال يدوي لصفحات الفهرس مثل `4-5` أو `4، 5`.
- إذا فشل الاستخراج الموثوق، تُمسح المسودة الرديئة السابقة بدل إبقائها في Supabase.
- لا يمكن اعتماد عنوان يبدو معادلة أو نصًا مشوهًا.

## خارج النطاق

- التعرف البصري على تصميم صفحة الفهرس.
- استخدام نموذج ذكاء اصطناعي لاستخراج البنية.
- استخراج نواتج التعلم.
