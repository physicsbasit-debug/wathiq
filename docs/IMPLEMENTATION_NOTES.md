# ملاحظات التنفيذ

## لماذا النموذج بلا إطار عمل؟

Phase 0-B نموذج UX محلي خفيف، صُمم دون اعتماديات تشغيلية حتى يمكن فحص المسار بسرعة. هذا لا يحسم بنية المنتج النهائية.

عند الانتقال للبناء الإنتاجي، يراجع الفريق خيارات الواجهة والخلفية وقاعدة البيانات والتخزين بناءً على نتائج قبول هذه المرحلة.

## فصل المنطق

- `domain.ts`: وظائف نقية قابلة للاختبار.
- `storage.ts`: الحفظ المحلي فقط.
- `data.ts`: بيانات تجريبية.
- `app.ts`: ربط الواجهة بالحالة.

## قاعدة حمراء

لا يُضاف تكامل Google Drive أو PDF أو AI إلى هذا النموذج مباشرة. كل تكامل يدخل في مرحلة مستقلة بمعايير قبول واختبارات واضحة.
