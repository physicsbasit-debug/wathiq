# التاريخ المختصر

## 0.3.0 — Cambridge Core Purge

- إزالة منظومة رفع المصادر وإدارة المحتوى من المنتج الحالي بالكامل.
- إزالة OCR ووظيفة `source-ocr` وكل وحدات السجل والفهرسة والاسترجاع المرتبطة بالملفات.
- تثبيت مسار واحد: برنامج كامبريدج + المرحلة/السيلابس + مادة العلوم + الموضوع.
- الحفاظ على المؤلف الحر والمراجع العلمي المستقل والتحقق الحتمي المحدود.
- إزالة الأنواع والحقول البصرية القديمة مثل variant/role ومسارات line-art/overlay.
- إصلاح مهام الصور بحيث تعمل IGCSE دون الاعتماد على رقم مرحلة عددي.
- تشديد حارس منع الأحافير وحارس العربية وRTL.
- تنظيف CSS والتصدير من بقايا واجهات ومكونات لم تعد موجودة.

## 0.2.0 — Cambridge-first Simplicity Reset

أصبح اسم الموضوع والمرحلة ومادة العلوم كافيًا لبدء التوليد، وأعيد فصل المؤلف عن المراجع العلمي. مهد هذا الإصدار لحذف منظومة المصادر بالكامل في 0.3.0.
