# تاريخ مختصر

## 0.1.0 — Quality Reset

حُذفت مولدات قديمة، Google Drive/OAuth، شجرة الكتاب الإلزامية، حراس التطابق اللفظي، وقوالب التأليف المفروضة. فُصل المؤلف عن المراجع العلمي، وأصبحت المرئيات التوضيحية 2D بلا line-art fallback.

## 0.2.0 — Cambridge-first Simplicity Reset

أعيد تعريف المسار الأساسي:

```text
برنامج Cambridge + Stage + مادة + موضوع
→ مؤلف حر
→ مراجع علمي مستقل
→ تحقق حتمي محدود
→ مرئي 2D عند الحاجة
→ تصدير
```

أهم القرارات:

- Cambridge Primary Science 0097 ضمن Stages 1-6.
- Cambridge Lower Secondary Science 0893 ضمن Stages 7-9، وبذلك Stage 7 و8 جزء أصيل من المخطط مع Stage 9.
- دعم علوم IGCSE بالأكواد المعروفة لكل مادة مدعومة.
- رفع الكتاب أو دليل المعلم أصبح اختياريًا بالكامل.
- إنشاء `global_curriculum` context عندما لا يوجد مصدر مرفوع.
- إزالة مرجع التقويم المحلي وحقول الهوية المحلية من ورقة الطالب.
- تبسيط نموذج المصدر الاختياري وإزالة الفصل الدراسي/الإصدار كمتطلبات.
- مستوى التفكير أصبح توجيهًا للمؤلف والمراجع، وليس قالبًا لغويًا صلبًا.
