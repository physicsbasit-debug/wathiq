# إعداد Supabase لواثق من الواجهة فقط

لا توجد أوامر طرفية في هذه الوثيقة. العالم نجا هذه المرة.

## 1. إنشاء مشروع Supabase

1. افتح لوحة Supabase.
2. أنشئ مشروعًا جديدًا باسم مناسب مثل `wathiq-production`.
3. احفظ كلمة مرور قاعدة البيانات في مكان آمن.
4. انتظر حتى يكتمل إنشاء المشروع.

## 2. إنشاء جدول سجل المصادر

1. افتح **SQL Editor**.
2. اختر **New query**.
3. افتح الملف الموجود في المستودع:
   - `supabase/phase_0_e_source_registry.sql`
4. انسخ محتواه كاملًا إلى SQL Editor.
5. اضغط **Run**.
6. تأكد من عدم ظهور خطأ.

الملف ينشئ الجدول والقيود وصلاحيات RLS، ويمنع المستخدم المجهول من الوصول.

## 3. إنشاء حساب مالك المنصة

1. افتح **Authentication**.
2. اختر **Users**.
3. اضغط **Add user**.
4. أدخل بريد مالك المنصة وكلمة مرور قوية.
5. فعّل تأكيد المستخدم مباشرة إذا ظهر الخيار.

لا تفعّل التسجيل العام للمستخدمين في هذه المرحلة.

## 4. الحصول على بيانات الربط

من لوحة Supabase:

1. افتح **Settings → API Keys** أو نافذة **Connect**.
2. انسخ:
   - Project URL
   - Publishable key الذي يبدأ بـ `sb_publishable_`

**لا تنسخ Secret key ولا Service Role.** تلك المفاتيح عالية الصلاحية ولا مكان لها في صفحة عامة.

## 5. إضافة متغيرات GitHub

داخل مستودع `physicsbasit-debug/wathiq`:

1. افتح **Settings**.
2. اختر **Secrets and variables → Actions**.
3. افتح تبويب **Variables**.
4. أضف المتغير الأول:
   - الاسم: `WATHIQ_SUPABASE_URL`
   - القيمة: Project URL
5. أضف المتغير الثاني:
   - الاسم: `WATHIQ_SUPABASE_PUBLISHABLE_KEY`
   - القيمة: Publishable key

هذه بيانات عامة منخفضة الصلاحية، والحماية الفعلية تأتي من تسجيل الدخول وسياسات RLS.

## 6. إعادة نشر GitHub Pages

1. افتح **Actions**.
2. اختر workflow: **نشر معاينة واثق**.
3. اضغط **Run workflow** على فرع `main` بعد دمج المرحلة.
4. انتظر نجاح البناء والنشر.

## 7. الاختبار

1. افتح رابط واثق.
2. ادخل إلى **إدارة المصادر**.
3. يجب أن تظهر بطاقة تسجيل دخول مالك المنصة.
4. سجّل الدخول بالحساب الذي أنشأته في Supabase.
5. إذا كان في المتصفح سجل محلي من Phase 0-D، سينقله واثق تلقائيًا إلى السجل المركزي دون حذف النسخة المحلية.
6. أضف مصدرًا جديدًا.
7. افتح واثق من متصفح أو جهاز آخر، سجّل الدخول بالحساب نفسه، وتأكد من ظهور المصدر.

## معالجة الإعداد الناقص

إذا لم تضف متغيرات GitHub، يعمل واثق في وضع **التخزين المحلي** ويعرض ذلك بوضوح. لا يفشل الموقع ولا يدّعي أنه متصل.
