## السيناريوهات المغطاة

- رسم خطي متعدد السلاسل مع مفتاح واضح.
- جدول بيانات منظم مع خلية ناقصة.
- تدريجات ميزان حرارة، وسحاحة، ومخبار مدرج، وأميتر/فولتميتر.
- مخططات انعكاس وانكسار وعدسة محدبة ومنشور.
- مخططات جسم حر وقوى متزنة وعزوم.
- مخططات تسلسل ودورة وتحولات حالة أو طاقة.
- تمرير الدور البصري: قراءة، حساب، تفسير، مقارنة، إكمال، رسم، تقييم.
- منع تحويل درس النشاط الإشعاعي إلى مخطط أشعة ضوئية.
- بناء المواصفة البصرية داخل الخادم، دون توليد صور حر.
- رفض HTML أو روابط أو صور خارجية داخل مواصفة SVG.
- قواعد طباعة بالأبيض والأسود.

## فحوص السلامة

- لا SQL جديد.
- لا تغيير في GitHub Pages workflow.
- لا سر أو مفتاح API داخل الحزمة.
- لا استدعاء `text-to-image` أو Imagen داخل وظيفة التوليد.
- حزمة الملفات المعدلة لا تحتوي `dist`؛ يبنيه GitHub Pages من المصدر.

## الحد المتبقي

- لم يُجر اتصال حي بمشروع Supabase أو مفتاح Gemini الخاص بالمستخدم.
- لم يُختبر النقر النهائي على Word/PDF داخل Chromium حي في بيئة التنفيذ.
- الصور المجهرية والتشريحية، واقتصاص صور الكتاب، وطبقة الإجابة الرسومية المستقلة ليست ضمن C3.
