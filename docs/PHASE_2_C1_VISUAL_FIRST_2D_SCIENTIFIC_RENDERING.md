# Phase 2-C1 — Visual-First 2D Scientific Rendering

## القرار

تنقل هذه المرحلة المرئيات في واثق من الاعتماد الظاهر على الرسوم الخطية الخام إلى نظام مرئي ثنائي الأبعاد ذي مستويين:

1. **صور تعليمية 2D مولدة ومدققة علميًا** للمشاهد السياقية الآمنة، مثل الكهرباء الساكنة والمواقف الحياتية.
2. **رسوم متجهية ثنائية الأبعاد منضبطة** للمخططات التي تحمل منطق الحل، مثل مخططات القوى والقيم والأسهم والوحدات.

لا تُترك القيم أو الوحدات أو الأسهم أو العلاقات الحسابية لمولد الصور الحر.

## الإصدار

- التطبيق: `0.0.53`
- عقد V2: `source-grounded-policy-ai-18-exam-integrity-resume`
- إصدار موجه الصور: `wathiq-visual-first-2d-v3-scientific-quality`
- الأساس: Phase 2-B Fix 1 (`0.0.52`)

## التغييرات

### توليد الصور

- توسعت أهلية الصور لتشمل مشاهد التجاذب والتنافر في الكهرباء الساكنة، إلى جانب الشحن بالدلك والمشاهد السياقية المؤهلة سابقًا.
- أصبح موجه الصور يطلب رسمًا تعليميًا ثنائي الأبعاد مناسبًا للطباعة، بخلفية نظيفة، وتسلسل بصري واضح، ودون نصوص أو أرقام أو وحدات أو أسهم داخل الصورة.
- يعيد واثق المحاولة مرة ثانية مع تمرير سبب الرفض إلى مولد الصورة.
- لا تُقبل الصورة إلا بعد تحقق مستقل من:
  - اكتمال العناصر المطلوبة.
  - صحة عدد العناصر.
  - صحة العلاقة العلمية.
  - خلو الصورة من النصوص والقيم والأسهم المحظورة.
  - وضوح التكوين ثنائي الأبعاد.
  - صلاحيتها للطباعة.

### تجربة الاستخدام

- خيار المرئيات الثنائية الأبعاد مفعّل افتراضيًا.
- ينتظر واثق تجهيز المرئيات قبل إنهاء مرحلة التوليد، بدل تشغيلها بصمت بعد عرض الاختبار.
- يجهز تلقائيًا حتى أربع مرئيات مؤهلة في الاختبار القصير.
- عند استئناف مسودة في مرحلة الخطة أو المراجعة، يبدأ تجهيز المرئيات المؤهلة غير المكتملة تلقائيًا.
- عند فشل التوليد أو الفحص، يستخدم واثق رسمًا متجهيًا ثنائي الأبعاد مصقولًا بدل تعطيل الاختبار.

### الرسوم المنضبطة

- مخططات القوى بقيت حتمية لضمان صحة القيم والاتجاهات، لكنها تعرض جسمًا ثنائي الأبعاد مناسبًا للسياق، مثل حقيبة مدرسية أو عربة أو صندوق، بدل مستطيل عام.
- تحسنت رسوم المسطرة وقطعة القماش وقصاصات الورق، ورسوم الجسمين المشحونين، بالألوان والعمق البصري الخفيف.
- أضيفت الأنماط نفسها إلى مسار Word/PDF وتحويل SVG إلى PNG حتى لا تضيع الألوان أو التفاصيل في التصدير.

## حدود المرحلة

- لا تُحوَّل مخططات القوى والدوائر والجداول والأجهزة الحسابية إلى صور AI حرة؛ تظل منضبطة برمجيًا.
- لم يتوفر اتصال حي بمفتاح Gemini ومشروع Supabase في بيئة التجهيز، ولذلك أول توليد صورة بعد النشر اختبار قبول إلزامي.
- عند فشل الصورة الحية يبقى الاختبار قابلًا للاستخدام عبر الرسم المتجهي المصقول.
