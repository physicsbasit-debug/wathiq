# صيانة مستودع واثق

## ما يبقى في `main`

- كود المسار الحالي فقط.
- اختبارات الانحدار التي تحمي السلوك الحالي.
- مخطط Supabase الحالي ووظائف Edge المستخدمة فعليًا.
- Workflows الحقيقية داخل `.github/workflows/`.
- وثائق التشغيل والمعمارية الحالية فقط.

## ما لا يبقى

- `dist/` أو أي نواتج بناء.
- ZIPs أو نسخ احتياطية.
- تقارير مراحل منتهية.
- ملفات Bootstrap/Reset بعد انتهاء تطبيقها.
- تعليمات رفع مرحلية.
- كود توافق أو اختبار يفرض بقاء مسار محذوف.
- أي وحدة رفع مصادر/OCR/Google Drive أو مولد قديم خارج فلسفة 0.3.0.

Git history هو أرشيف التاريخ. لا نحتفظ بالأحفورة داخل شجرة التشغيل «للاحتياط».

## بوابات الدمج

```bash
npm run repo:check
npm run legacy:check
npm run ui:check
npm run test
```

أو الأمر الجامع:

```bash
npm run check
```

- `repo:check`: نظافة بنية المستودع.
- `legacy:check`: يمنع عودة الكود القديم المحظور.
- `ui:check`: العربية وRTL ورسائل المستخدم.
- `test`: البناء والاختبارات السلوكية الحالية.

لا تدمج مرحلة إذا فشل أي حارس.

## Repository Maintenance

يوجد Workflow باسم `Repository Maintenance` ويمكن تشغيله يدويًا من Actions. الحذف الآلي محصور في أنماط معروفة، ولا يقرر من تلقاء نفسه حذف كود مصدر لمجرد أنه غير معروف.
