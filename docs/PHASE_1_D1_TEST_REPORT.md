## ما غطته الاختبارات

- بناء TypeScript والملفات الثابتة.
- ترقية المسودات القديمة وتفعيل الخيار افتراضيًا مع احترام التعطيل الصريح.
- تحليل بيانات الصورة المقبولة ورفض البيانات غير الآمنة.
- منع AI من مخططات القوى والرسوم الحساسة.
- إبقاء SVG خلف الصورة المدققة.
- إضافة القيم والوحدات إلى الرسوم الحسابية.
- تشكيل طلب صورة 2D المقيد.
- استخدام نموذج الصور وإعداد النسبة والحجم في وظيفة Supabase.
- الفحص العلمي البصري قبل التخزين.
- إنشاء حاوية الصور ورفع الأصل وإرجاع الرابط.
- الرجوع الحتمي عند الرفض أو الفشل.
- توافق Word وPDF مع الصورة والبديل الحتمي.
- استمرار جميع اختبارات المراحل السابقة.

## فحوص إضافية

- نجاح `npm run build`.
- لا SQL جديد.
- لا أسرار أو ملفات `.env` داخل الحزمة.
- لا تغيير في GitHub workflow.
- `dist/` يبنى من المصدر ولا يدخل حزمة الملفات المعدلة فقط.

## قيد الاختبار

لم يُنفذ طلب حي باستخدام مفتاح Gemini أو مشروع Supabase الحقيقي من بيئة التجهيز. الاختبارات تحاكي استجابات توليد الصورة والفحص والتخزين، ولذلك يجب تنفيذ اختبار قبول حي واحد على الأقل بعد إعادة نشر الوظيفة.
